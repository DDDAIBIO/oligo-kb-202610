## 3. A/B/C 分级（定级器：任何材料先过这一关）

| 级别 | 判据 | 核对动作 |
| --- | --- | --- |
| **A 可计算** | 能写出伪代码，输入输出一一对应 | 让对方现场写伪代码；写不出 = 包装 |
| **B 可预测** | 能说清训练集是什么 | 问"训练集从哪来、误差多大"；说不清 = 空话 |
| **C 只能实验** | 找不到可观测替代量 | 宣称可预测 = 骗子；组织暴露、内体逃逸、on-target 毒性、免疫个体差异都在这级 |

## 4. 我占哪两格（定位结论，M1 不改）

1. **② 位点层 = 纯 A 级计算，已上线第一个工具**（scan_sites）。这是转型以来第一个"能给别人用"的东西。
2. **⑥ 验证层 = 老本行 + SOP 化**。产出物不是分析结果，是湿实验同事能跑的 SOP（D22 已立骨架）。
3. **横切专利层做"检索那 10%"**：BLAST PAT 分区 + 特征矩阵，法律结论永远不归我出。

**执行优先级（写代码的顺序）**：`offtarget_scan.py`（③）与 `claim_hit.py`（横）合并做一个脚本的两个模式——输入都是"药物序列 + 修饰描述"，一个查转录组、一个查专利库。

## 5. 使用规则（这张图什么时候打开）

- 新项目立项：先跑 §2 表的 ①②横 三格，出"可计算预筛报告"，再谈设计；
- 收到外部材料（论文/公司 PR/推销）：先过 §3 定级，A 级拿伪代码、B 级问训练集、C 级直接标"只能实验"；
- 任何一格的否决项（打不到 / 被专利覆盖 / C 级毒性）出现 → 回到 §2 对应行，看"v1 状态"列决定补工具还是换方向。
