## 这个坑（2026-11-22，D32 备料时被用户一问戳破）

- **触发**：用户问"Mol Ther—Nucleic Acids 2020 GalNAc 综述在哪能查到"——我按这个名字去搜，搜不到；实际是**刊名写反了**。
- **真相**：两篇综述被我混淆，刊名正好对调。

| | 我原来写的 | 实际 |
|---|---|---|
| Debacker 2020（给主线/数字） | ~~Mol Ther—Nucleic Acids~~ | ***Mol Ther* 正刊 28(8):1759–1771**，DOI `10.1016/j.ymthe.2020.06.015`，PMID 32592692，PMC7403466 |
| Huang 2017（给专利原则/原话） | ~~PMC GalNAc 综述（无刊名）~~ | ***Mol Ther Nucleic Acids* 6:116–132**，DOI `10.1016/j.omtn.2016.12.003`，PMID 28325278，PMC5363494 |
| Foster 2018（NHP 数据原始文） | ~~Mol Ther—Nucleic Acids~~ | ***Mol Ther* 26(3):708–717**，DOI `10.1016/j.ymthe.2017.12.021` |

- **为什么容易错**：*Molecular Therapy* 与 *Molecular Therapy—Nucleic Acids* 同属 Cell Press / ASGCT 家族、刊名是包含关系、缩写都以 "Mol Ther" 开头；两篇又都是 GalNAc 综述、都讲 ESC。**主题、家族、缩写三重撞车**。
- **代价**：链接其实是对的（`S1525001620303051` 就是 Mol Ther 的 PII），所以"点进去能读到、只是引用写错"——这种错最难自查，因为打开后内容完全对得上，不会触发任何警觉。若照此写进汇报或专利分析，就是硬伤。

## 怎么避免（已变成检查项）

1. **给每篇文献存 PMID/DOI，不存"刊名 + 年份"的自由文本**（C4 的同一条纪律，这次是它的第二个变体）。
2. **Cell Press 家族的 PII 前缀可直接判刊**：`S1525-0016` = *Mol Ther*；`S2162-2531` = *Mol Ther Nucleic Acids*。看到 PII 就能核刊名，不用打开全文。
3. **同主题多篇综述要"分工表"而不是"清单"**：现在 D32 §3 已改成每篇只标一件事（2020 给主线与数字 / 2017 给专利原则与原话 / 2018 中文给具体位点模式），分工一写清，就不容易再把两篇当成一篇。
4. **顺带收获**：借这次核实，把两个 🟡 一起核掉了——**280× 剂量差**（原文 "280-fold lower"，同文 28 g/年 vs 100 mg/年 自洽）与 **Foster 题录**（2018 *Mol Ther* 26(3):708–717）。
