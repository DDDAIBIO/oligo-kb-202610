## 1. 先分清三种"打不到"

**失败模式不同，能不能提前算出来完全不同。** 这是位点层的第一课：

| 失败模式                   | 机制                           | 能否靠计算提前发现            |
| ---------------------- | ---------------------------- | -------------------- |
| **A. 靶序列根本不在这个细胞里**    | 转录本选错 / 组织表达不对 / 只表达某个异构体    | 🟡 部分可算（表达谱 + 异构体比对） |
| **B. 序列在，但被结构或蛋白挡住**   | 二级结构、RBP 占据、核糖体通过            | 🟡 只能粗筛（可及性 ≠ 真实构象）  |
| **C. 序列在，但你的药进不去那个区室** | ⭐ siRNA 在**胞质**工作，只能打成熟 mRNA | ✅ **完全可算，且最常被忽略**    |

C 类是最硬的机制约束，也是最好用的筛子：

```
siRNA  → 胞质 → 只能打【成熟 mRNA】 → 内含子、pre-mRNA 一律无效
gapmer → 核内为主（RNase H）→ 【pre-mRNA 也能打】→ 内含子可用
剪接调控 ASO → 必须打【内含子 / 外显子-内含子交界】→ 只能打 pre-mRNA
```

> 一句话：**模态决定区室，区室决定哪一段能用。** 先问"我的药在哪工作"，再问"哪一段好"。

## 2. 第一步：选转录本（覆盖率决定生死）

一个基因常有多个异构体。**你设计的 21-mer 如果落在某个"可变外显子"上，那它只对一部分转录本有效。**

工具约定：**MANE Select** —— RefSeq 与 Ensembl 对齐后，**每个基因选一个代表转录本**，两端 UTR 也一致。行业默认拿它当"标准答案"。

但要注意两件事：

- **MANE Select 不是"唯一表达的那个"**。肝、肌肉、脑的异构体比例可以差很多。
- **故意只打某个异构体，是 feature 不是 bug**。例如只打膜型不打可溶型——这时要反过来用覆盖率。

**做法**：把候选序列对该基因**全部**转录本做比对，算出"命中几个 / 共几个"。

| 覆盖率    | 判断                  |
| ------ | ------------------- |
| ≥ 90%  | ✅ 通过（几乎所有异构体都能打）    |
| 50–90% | 🟡 降级，记录"对哪些异构体无效"  |
| < 50%  | ❌ 弃（你可能只是在打一个次要异构体） |

## 3. 第二步：选区室（CDS / 3′UTR / 5′UTR / 内含子）

| 区域        | siRNA    | gapmer | 剪接 ASO   | 特点                                                 |
| --------- | -------- | ------ | -------- | -------------------------------------------------- |
| **CDS**   | ✅        | ✅      | ❌        | 表达稳定、注释最全；有核糖体通过（利于解链，也可能挡位点）                      |
| **3′UTR** | ✅        | ✅      | ❌        | ⭐ 避开起始密码子与可变剪接；调控区常更保守。代价：miRNA 位点/RBP 密集、可变 polyA |
| **5′UTR** | 🟡 慎     | ✅      | ❌        | 起始密码子附近有扫描中的核糖体，位点可用性差                             |
| **内含子**   | ❌ **无效** | ✅      | ✅ **必须** | siRNA 进不了核 → 直接排除                                  |

**两个真实案例，正好一枚硬币两面：**

- **Patisiran 打的是 TTR 的 3′UTR**（具体位点待核原文）。为什么可以？因为 siRNA 只要 mRNA，3′UTR 完全够用，而且避开了可变剪接带来的异构体差异。
- **Nusinersen 打的是 SMN2 的 intron 7（ISS-N1）**。为什么必须打内含子？因为它的目的是**改剪接**，靶点本身就在内含子里。

**这里有个必须点破的矛盾**：经典设计规则（Reynolds 2004 一系）明确建议「靶区取起始密码子下游 50–100 nt，**避开 5′ 和 3′ UTR**」。而真实获批的 Patisiran 就打 3′UTR。

> **设计规则是统计偏好，不是物理禁令。** 规则来自早期报道性筛选，样本偏向"高效序列"；  
> 真实项目里，3′UTR 因为保守 + 异构体一致，反而是好选择。**看到规则和案例冲突时，先查案例的机制理由。**

## 4. 第三步：可及性（accessibility）到底在算什么

**它算的是**：这条 RNA 在溶液里自己折起来之后，某个位置"没配对上、暴露在外"的概率。

**工具**：`RNAplfold`（ViennaRNA 包）。滑动窗口内计算碱基配对概率，输出每个位置的 **P(unpaired)**。常用参数 `-W 80 -L 40`（窗口 80 nt、最大配对跨度 40 nt）。

**用法**：对候选窗口取平均 P(unpaired)，排序，高的优先。

**三条必须承认的边界**（这也是我把它归 A 级但不算"判决"的原因）：

1. **相关性中等**：文献支持可及性影响效力，但单独解释力有限（相关系数量级 0.3–0.5，具体值待核）。**它擅长排掉最差的，不擅长挑出最好的。**
2. **体外折叠 ≠ 细胞内**：RBP 占据、翻译中的核糖体、RNA 修饰（m6A 等）都会改变真实构象。你算的是"裸 RNA 在缓冲液里"。
3. ⚠️ **别忘了 siRNA 自己也要可及**：反义链的种子区如果埋在自身二级结构里，装载 RISC 就受影响——这是"靶标可及性"之外的第二张图。

> 结论一句话：**可及性是粗筛（去掉最差 30%），不是判决。**

## 5. 第四步：SNP 掩蔽（这一步最有计算含量）

**为什么必须做**：靶位点里只要有一个常见 SNP，你的药对这部分人就**完全或部分失效**——而且是"看起来很有效、实际有 10% 人群无效"的那种隐性失败。

**最严重的位置是种子区**：反义链 2–8 位对应的靶标 2–8 位，只要有一个错配，miRNA 样的识别就崩了（切割可能还行，但整体效力骤降）。

**做法（4 步）**：

1. 从 gnomAD 拉该窗口内的所有变异（注意人群分层：东亚频率可能和全球差很多）
2. 筛 **MAF ≥ 1%** 的常见变异
3. 判定位置：落在**种子区**（最重）/ 中央（中等，切割位点约在反义链 10–11 位对面）/ **反义链 3′ 端**（最轻；注意它对应的是**靶位点的 5′ 端**，别搞反）
4. 算**人群覆盖率** = 1 − Σ 变异携带者频率

| MAF  | 落在种子区   | 落在中央  | 落在 3′ 端 |
| ---- | ------- | ----- | ------- |
| ≥ 5% | ❌ 排除该位点 | 🟡 降级 | 🟡 记录   |
| 1–5% | 🟡 降级   | 🟡 记录 | ✅ 保留    |
| < 1% | ✅ 保留    | ✅ 保留  | ✅ 保留    |

**一个实操坑，先记住**：靶序列给的是**正义链**，gnomAD 变异坐标在**基因组正链**上。转录本在负链时，坐标要反向取补——**做错这一步，你会把 SNP 掩到完全不相干的位置，而且结果看起来完全正常**。这是明天写脚本时最容易静默出错的一行。
