## 1. 脱靶三分类（判断"能不能算"的第一刀）

| 类别 | 机制 | 谁会中招 | 能否靠计算提前筛 |
| --- | --- | --- | --- |
| **A. 序列依赖**：部分同源打偏 | guide/passenger 与别的 RNA 互补 | 全部反义模态 | ✅ **纯计算，今天的主菜** |
| **B. seed 介导（miRNA-like）** | siRNA guide 2–8 位像 miRNA 一样压 3′UTR | siRNA 为主 | ✅ 可算（seed 匹配富集） |
| **C. 化学类效应** | 骨架/糖修饰/递送本身的毒性、TLR 激活、RISC 饱和 | gapmer（肝）、高剂量 siRNA | ❌ 只能实验（C 级，D18 分级） |

三类的验证手段完全不同，**SOP 里必须分开报，不能混在一个 off-target 列表里**：

- A 类 → 序列对转录组搜索（计算先行，实验确认）
- B 类 → 下调基因 3′UTR 的 seed 匹配**富集检验**（不是逐基因找匹配）
- C 类 → 对照化学匹配 + 临床化学指标（ALT/AST 等）+ 剂量梯度可逆性

> 与 D15 的接口：TLR/免疫激活当年归为"免疫原性"，在验证层它就是 C 类的一部分——
> 同一现象，两个视角，报告时写进 C 类。

## 2. 各模态的脱靶"主战场"不一样

| 模态 | 主要脱靶形态 | RNA-seq 里看什么 | 特别提醒 |
| --- | --- | --- | --- |
| **siRNA** | B 类 seed 下调（大量、幅度小）+ A 类 | **下调基因是主角**；3′UTR seed 富集 | passenger 链也能带脱靶，两条链都要算 |
| **gapmer** | A 类脱靶敲低 + C 类化学肝毒性 | 下调基因 + **临床化学指标** | RNase H 只需部分连续互补即可切割，连续匹配阈值文献间有差异 🟡 |
| **剪接 ASO** | **脱靶剪接改变**（不是表达下调） | 剪接事件分析（rMATS / MAJIQ 一类工具） | ⭐ 换问题：不是"谁的量变了"而是"谁的剪接变了"，常规 DESeq2 流程会漏 |

⭐ 剪接 ASO 这行是你十年 DESeq2 惯性最容易漏的：**脱靶的表现形式由作用机制决定**。
机制是催化切割（siRNA/gapmer）→ 看丰度；机制是占位（steric blocking）→ 看剪接/ polyA 选择。

## 3. 实验设计的四臂对照（SOP 的地基，算力替代不了）

任何脱靶 RNA-seq，对照设计错了后面全是白工。四臂缺一不可：

| 臂 | 内容 | 排除什么 |
| --- | --- | --- |
| 1 | 只加转染试剂 / 赋形剂 | 转染本身的应激 |
| 2 | **化学匹配的非靶向对照**（同修饰、同骨架、同递送，序列不靶向任何转录本） | C 类化学效应 |
| 3 | 目标药 | — |
| 4 | **seed-matched / 错配梯度对照**（只改 guide 的 seed 或中部几个碱基） | B 类 seed 效应 |

配套参数（行业常规，具体数值按实验体系微调）：生物学重复 n≥3；至少两个剂量
（临床相关剂量 + 倍数放大）；siRNA 看表达一般取 24h 前后两个时间点。

> 一句话：**臂 2 排化学，臂 4 排 seed**。只跑臂 1 vs 臂 3 的"两点对比"是脱靶分析最常见的设计错误。

## 4. ⭐ 核心交付：脱靶验证 SOP v0（骨架）

> 写法约定：每步只写"执行要点 + 判断标准"，湿实验同事能直接照做；
> 带你的生信手艺的细节（S2/S3）一句话带过——你不缺这块知识，缺的是把它钉进 SOP。

| 步 | 做什么 | 判断标准 |
| --- | --- | --- |
| **S0 设计** | §3 四臂 + 重复/剂量/时间点；**先冻结随机化方案** | 四臂齐全才放行进 S1 |
| **S1 样本** | RNA 抽取（含 DNase）、RIN、浓度；分装备份 | RIN ≥ 7（ industry 常规线）；不合格重抽，不硬上 |
| **S2 文库** | ⭐ **链特异性文库**；⭐ 打内含子/pre-mRNA 的模态（gapmer、剪接 ASO）用 **rRNA-deplete 而非 polyA**（polyA 会把 pre-mRNA 信号滤掉）；depth ≥ 20–30M | 文库类型按模态定，S0 时就写死 |
| **S3 定量** | fastp → STAR/HISAT2 或 Salmon → DESeq2（你的老流程，不展开） | 下调是主角：LFC < 0 方向单独成表；记录比对率/定量化，异常样本在 QC 阶段拦下 |
| **S4 归因** | 每个显著下调基因贴标签：A（长连续匹配）/ B（3′UTR seed 匹配）/ C（剂量可逆 + 化学对照也变）/ 未归因 | ① 药物序列对转录组全库搜索（§5）；② 下调基因 3′UTR 的 seed 富集做超几何检验（工具可用 Sylamer 一类 🟡具体选型待核）；③ 对照臂交叉核对 |
| **S5 报告** | 固定列：gene / baseMean / log2FC / padj / 归因类别 / 证据（匹配位置、E-value）；附 GO/通路；**毒性基因清单 cross-check**（肝毒相关基因等，清单 v0 可先空着） | 三类分开成三张表；未归因单列；**不给"无脱靶"这种绝对结论**，只给"在当前深度/剂量/时间点下未见 X 类信号" |

**S5 的口径纪律直接沿用知识库既有规矩**：禁止"可能/有望"，每条带日期与版本；
"未检出"必须带条件（深度、剂量、时间点），否则就是句废话。

## 5. 计算切入点：`offtarget_scan.py` = D21 的镜像

D21 的问题是"**给定转录本，找候选窗口**"；验证层的问题是反过来的：

> **给定药物序列（21-mer 或 gapmer），在全转录组里找所有能打的地方。**

同一个窗口逻辑，主语互换：

```
D21  scan_sites.py   : 转录本 → 窗口 → 对自己打分
D22  offtarget_scan.py: 药物序列 → 全转录组库 → 找 ≥N 连续匹配 + seed 匹配 → 输出脱靶清单
```

v0 规格（C 档今天就能写，纯字符串操作，不依赖外部库）：

1. 输入：药物 guide 序列（含修饰字母表——沿用 D21 教训，字母表必须含修饰字母）+ 转录组 FASTA（mane 当主库，全部异构体当全库）
2. 三档匹配输出：
   - 全同匹配（gene, 位置）→ A 类铁证候选
   - ≥12 连续匹配（阈值 🟡 待核文献）→ A 类候选
   - seed（guide 2–8 位）在任一 3′UTR 的匹配 → B 类候选（需 3′UTR 区间注释，v0 可退化为全转录本匹配 + 标注"位置未定性"）
3. 输出排序：按匹配长度降序、同长按基因名（可复现，沿用 D21 纪律）
4. 比对方式 v0 用朴素搜索即可（转录组 ~几十 MB，够快）；v1 再上 suffix array / hisat2 --sensitive

⭐ 这就是"验证层反哺设计层"的闭环：`offtarget_scan` 的输出直接当 `scan_sites`
的第六个打分维度的输入（v1 把"无 A/B 类脱靶"写进判据）。

## 9. 明日预告（D23 · 专利与 FTO）

FTO（Freedom to Operate）三步法：权利要求怎么读（序列到底保护"序列本身"还是"序列+修饰+递送"的组合）、检索入口、以及计算人能做的那一小块（序列比对查权利要求覆盖）。法律格是 C 级（不能算），但**检索与比对那 10% 是 A 级**。
