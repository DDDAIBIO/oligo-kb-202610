## 2. 结论一：Cemdisiran —— **还没批**，PDUFA 就在本月

### 2.1 事实（全部来自一手或权威综述）

| 项 | 内容 |
|---|---|
| 分子 | cemdisiran（原 ALN-CC5），GalNAc-siRNA |
| 靶点 | 补体 **C5**（肝内合成） |
| 给药 | **皮下，每 12 周一次（Q12W，一年 4 次）** |
| 适应症 | 成人 **AChR 抗体阳性全身型重症肌无力（gMG）** ← 不是 PNH |
| III 期 | **NIMBLE**，随机 284 例（cemdi 79 / pozelimab 50 / 联合 80 / 安慰剂 75） |
| 主要终点 | 24 周 MG-ADL 变化：cemdi 组 −4.5，**较安慰剂改善 2.3（p<0.001）**；76.6% vs 44.1% 改善 ≥3 分 |
| 关键次要 | QMG 改善 4.2，较安慰剂 2.8（p=0.002） |
| 发表 | *The Lancet* + AAN 2026 年会（2026-04） |
| 监管 | NDA 受理 2026-06-22，**优先审评（用了一张 PRV）**，目标决定日期 **2026-11**；EU 预计 2027 H2；日本 2027 初申报 |
| **11-10 判定** | **截至 2026-11-10 未见获批公告 → 状态仍是"在审"** |

### 2.2 三个容易踩的点

1. **"NDA 在审" ≠ "已获批"**。库里去年的写法是"预计 2026-11 出结果"，这句话到今天仍然成立，但它**不能升级成"已获批"**。
2. **证据粒度不同**：官方只说"11 月"；聚合站（pdufa.bio）给了 **11-30** —— 那是外部推算的具体日，引用时要说清来源层级，别把聚合站的日期当成 FDA 承诺。
3. **适应症别记错**：lead indication 是 **gMG**。早期和 pozelimab 联合做的是 PNH，但**申报上市的是单药 gMG**。

### 2.3 🔴 计数更正：不是"第 5 款"，是"第 8 款"（C7）

D8 笔记里写"若获批将是第 5 款 GalNAc-siRNA"——**这个数字错了**。

Cell Rep Med 2026 综述原文：`a total of 6 additional GalNAc-siRNAs are now on the market`，加上首款 givosiran，**已上市 7 款**：

| # | 药物 | 获批 |
|---|---|---|
| 1 | givosiran | 2019-11 |
| 2 | lumasiran | 2020-11 |
| 3 | inclisiran | 2021-12（FDA） |
| 4 | vutrisiran | 2022-06 |
| 5 | **nedosiran** | 2023-09 ← D8 时漏了 |
| 6 | fitusiran | 2025-03 |
| 7 | plozasiran | 2025-11 |
| 8 | **cemdisiran（若获批）** | 2026-11 待决 |

错因很清楚：写的时候脑子里只有"givosiran / lumasiran / inclisiran / vutrisiran"四款，**漏了 nedosiran（2023）和 fitusiran（2025）**。

> 📌 **通用教训**：`第 N 款`、`共 M 个` 这类断言**必须带日期 + 当场重数**。它们是全库最容易悄悄过期的一类事实，而且过期后看起来完全正常。

## 3. 结论二：del-desiran —— HARBOR **确认失败**（2026-09-08）

### 3.1 从"待核验"升级为"已核实"

D8 时这条只有二手来源，标了 🟠。今天两个独立来源确认：

| 项 | 内容 |
|---|---|
| 分子 | delpacibart etedesiran（del-desiran，AOC 1001）= **抗 TfR1 单抗 + DMPK siRNA** |
| 疾病 | **1 型强直性肌营养不良（DM1）** |
| 试验 | **HARBOR**，III 期，**159 例**、约 40 个中心、随机双盲、**每 8 周给药**、**54 周** |
| 主要终点 | **vHOT（视频手部张开时间）** —— 未达统计学显著 |
| 次要/探索 | 部分临床活性信号；安全性与此前一致 |
| 公布 | 2026-09-08（Novartis），当日股价 **−10%** |
| 归属 | Novartis 2025-10 宣布、**2026-02 完成**收购 Avidity（约 **120 亿美元**），del-desiran 是其最贵资产 |

### 3.2 关键对照：MARINA（I/II 期）明明很漂亮

NEJM 2026-02-19，38 例：

- 肌肉活检 **DMPK mRNA 下降 46% / 44% / 37%**（1 / 2 / 4 mg/kg），安慰剂组 **+0.9%**
- 剪接异常复合评分改善 **17% / 16%**（2 / 4 mg/kg），安慰剂 7%
- vHOT、定量肌力、10 米步行、TUG、生活自理量表**方向都是改善**

**递送成立、靶点打中、剪接修回来了一部分 —— 功能终点还是没过。**

### 3.3 为什么？（三级台阶模型，这是今天最值钱的一张图）

```
①靶点敲低  →  ②通路修复  →  ③功能获益
   DMPK↓40%     剪接改善17%      vHOT 未达显著
   ✅ 踩稳       ✅ 踩稳          ❌ 没跨过去
```

三条可能的断点（都不互斥）：

1. **DM1 是多系统病**：骨骼肌只是其中一部分，CNS 与心脏受累不会跟着肌肉指标改善
2. **剪接损伤是累积的**：已经形成的结构性改变，不会在 54 周内被逆转 —— 窗口可能太短
3. **终点本身噪声大**：vHOT 直观，但重复性与最小临床重要差异（MCID）一直是方法学争议点

> 🔗 回连 D14 的 Eteplirsen：肌肉类核酸药**共用同一个瓶颈** —— 递送到了、分子降了，**功能指标却难以撬动**。
> Eteplirsen 是 109 g/年 换 0.93% 蛋白恢复；del-desiran 是 120 亿美元换一个未达标的 vHOT。**同一类失败，两种价格。**

### 3.4 不要混淆：del-brax 是**另一个分子**

| | del-desiran（AOC 1001） | del-brax（AOC 1020） |
|---|---|---|
| 靶点 | DMPK | **DUX4** |
| 疾病 | DM1 | **FSHD** |
| 状态 | **III 期失败（2026-09）** | I/II 生物标志物阳性，正与 FDA 谈下一步 |

FSHD Society 专门发过声明强调两者不同（因为社区里已经混了）。**写笔记时务必带分子代号，别只写"Avidity 的 AOC"。**

### 3.5 对 D6 判断的处置：不改结论，改权重

D6 我们说 **AOC 是"唯一在解决空间瓶颈的方向"** —— 这个判断**不变**（肝外递送仍然只有它在临床验证）。
但要加三条限定：

1. **下调"平台成熟度"权重**：第一次大规模 III 期就没过，工程化难度比预期高
2. **区分"递送成功"与"临床成功"**：MARINA 已经证明 TfR1 能把 siRNA 送进肌肉 —— AOC 的**递送命题已解**，卡的是**疾病可逆性**
3. **不要用 del-desiran 否定整条赛道**：DYNE-251（DMD exon 51）已递交 BLA，del-brax 在推进 —— **同一平台正在分叉**

## 4. 顺手发现（不在待办里，但比待办更重要）

### 4.1 2026-10-20：bepirovirsen 获 FDA 批准（Hibsago）

**首个慢性乙肝"功能性治愈"药物**，也是 ASO 第一次打进超大人群的慢性传染病。

| 项 | 内容 |
|---|---|
| 分子 | bepirovirsen，**ASO（Ionis 原创，GSK  licensed）** |
| 给药 | **皮下，每周一次 × 24 周**，叠加在核苷（酸）类（NRTI）之上 |
| 适应症 | 无肝硬化的慢性 HBV，NRTI 治疗 ≥6 个月、HBV DNA 已抑制、**HBsAg ≤3000 IU/mL** |
| III 期 | B-Well 1/2，29 国、**1838 例** |
| 疗效 | **功能性治愈 19%**（233/1220）vs 安慰剂 **0/614**；HBsAg ≤1000 亚组 **26%** |
| 先行 | 2026-08 日本首发 |

**为什么这条对你有用**：

- **ASO 的"化学计量"劣势被疗程消化掉了**：每条 pre-mRNA 需要一个 ASO、不能像 RISC 那样催化放大（D14 的肌肉故事），但 HBV 是**有限的肝内靶标 + 24 周集中给药**，剂量堆得上去。
- **终点革命**：「功能性治愈」（停药后 HBsAg 持续消失）是个**硬终点**，不是替代终点 —— 对照 pelacarsen（Lp(a) 降了、事件没降）和 del-desiran（分子降了、功能没动），三种结局正好凑成一组对照。
- **靶点类型**：从"人的基因"扩到"病毒的 RNA"。这打开了 ASO/siRNA 的第二个适应症宇宙（HBV、HCV、RSV…）。

## 6. 术语补 3 条（→ 35）

| 术语 | 一句话 |
|---|---|
| **PDUFA 日期** | FDA 对新药申请作出决定的**目标日期**（处方药使用者付费法案规定），不是承诺日，可提前或延后 |
| **顶线结果（topline）** | 试验锁库后**首次公布的主要终点结论**，通常只有方向与显著性，不含完整数据；"顶线未达"= 主要终点失败 |
| **功能性治愈（functional cure）** | 停药后**持久**清除病原体标志物（如 HBsAg 持续转阴），但体内未必彻底无病毒；与"根治"不同 |

## 8. W2 硬检验（合上资料答，别翻笔记）

1. 患者问：「我这个药为什么输液前要先打激素和抗过敏药？」——怎么答？
2. 有人说：「这款 LNP 的 pKa 做到 6.4，肯定有效。」——这句话错在哪？
3. 「GalNAc 已经把递送问题解决了。」——错在哪？

<details>
<summary><b>参考答案（先自己答，再展开）</b></summary>

**1.** 因为 Patisiran 是大剂量 LNP 静脉给药，颗粒本身会触发输注相关反应（IRR）。label §2.2 标题就是 "Required Premedication"，四联：地塞米松 10 mg（IV）+ 对乙酰氨基酚 500 mg（口服）+ 苯海拉明 50 mg（IV）+ 法莫替丁 20 mg（IV），输注前 ≥60 分钟，原文 "All patients should receive" —— **这是获批前提，不是可选项**。

**2.** 三个错：① **表观 pKa 是配方属性，不是分子属性**（MC3 分子胺 9.46 / 表观 6.44），单说一个数没有意义，得说清是哪个层面、什么配方下测的；② **区间因途径而异**（siRNA 肝 6.2–6.5，i.m. 疫苗 6.6–6.9），6.4 对肝是对的、对肌肉注射可能偏低；③ **pKa 只决定"能不能从内体逃出来"这一环**，还有粒径、PEG 密度、N/P、载药量、靶细胞受体密度，单指标不足以断言有效。

**3.** GalNAc 只能进**肝细胞**（ASGPR 只在肝细胞高表达、且是内吞型受体）。它解决的是"肝内递送 + 皮下给药"，**肝外（肌肉/心肌/CNS/脂肪）一个都没解决** —— 那正是 AOC、鞘内、C16 等方向要打的仗。说"解决了递送"，等于把 9 款肝靶向药的成功当成了整个递送问题的答案。

</details>

## 9. 下一步：W3（第 4 周）研发流程与计算切入点

D17 之后不再学"药怎么设计"，改学**"你在研发链条的哪一格"**：

```
靶点选择 → 序列设计 → 化学修饰 → 递送设计 → 体外验证 → 体内验证 → CMC → IND/临床
   ↑          ↑          ↑          ↑                    ↑
 生信/AI最强  算法+ML    规则+知识     ML辅助(进阶)       ★ 你的老本行
```

- **靶点层**：组学挖掘、遗传学证据（GWAS / 孟德尔随机化）、Open Targets
- **设计层**：规则引擎、热力学/结构计算、脱靶规避 ← 本计划主战场
- **验证层**：qPCR / RNA-seq 表达验证、**转录组-wide 脱靶检测** ← 10 年生信经验直接变现的位置
- **专利层**：序列 FTO 检索（单人团队必须会）
