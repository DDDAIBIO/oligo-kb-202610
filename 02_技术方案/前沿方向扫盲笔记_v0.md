## 一句话结论

前五个模态（ASO / siRNA / mRNA / 适配体 / 编辑）已经把"**关闭一个基因**"和"**表达一个蛋白**"两件事做成了产业。
剩下的瓶颈只有三个：**去哪里（空间）、做什么（动作）、撑多久（时间）**。
四个前沿方向不是并列的新技术，而是**各补一格**：

| 未解维度 | 现状的第一个瓶颈 | 补位方向 |
|---|---|---|
| **空间** | GalNAc 只到肝；LNP 主要到肝 | **AOC**（抗体带路） |
| **动作** | 只能降解/占位，不能改写；只能下调不能上调 | **ADAR 编辑**（改写）、**saRNA**（上调） |
| **时间** | 线性 mRNA 表达只有 24–48 h | **circRNA**（闭环抗降解） |

> **一句话记住**：AOC 改的是"分布团"，ADAR / saRNA 改的是"药效团"，circRNA 改的是"药代"。
> 它们分别对应 D1 那张解耦图里的不同列——这就是判断一个新方向值不值得跟的坐标系。

# 第一部分 · AOC（Antibody-Oligonucleotide Conjugate，抗体偶联寡核苷酸）

## 是什么

**抗体 + 连接子 + siRNA/ASO** 的共价偶联物。用抗体的组织特异性，**替换掉** GalNAc 的"肝特异性"。

| 组分 | 功能 | 对应 D1 的哪个"团" |
|---|---|---|
| 单抗（常用 **抗 TfR1**） | 决定去哪个组织 | **分布团 dianophore** |
| 连接子（多为可裂解） | 血循环稳定、进细胞后断开释放 | 装配工艺 |
| siRNA / ASO | 决定打哪个基因 | **药效团 pharmacophore** |

## 解决什么：肝外递送（目前行业的头号难题）

- GalNAc 只认 ASGPR → **只有肝细胞**
- LNP 靠 ApoE 吸附被动去肝，**没有主动靶向**
- ⇒ **肌肉、中枢、免疫细胞几乎是一片空白**，而这三类恰好覆盖了绝大多数罕见病

**为什么全行业都挑 TfR1（转铁蛋白受体 1）**：

- 骨骼肌和心肌上表达量高，且**天然内吞效率高**（本来就是运铁的）
- 已有先行者验证：JCR 的 **pabinafusp alfa**（IDS 酶 + 抗 TfR1 抗体融合蛋白，MPS II）已在日本获批，证明了 **TfR1 跨 BBB / 进组织**的商业可行性

## ⭐ 计算切入点

1. **连接子 / DAR 建模**：DAR（drug-to-antibody ratio）分布、连接子裂解动力学 → 经典 ADC 已有一整套数学模型，可直接迁移

# 第二部分 · ADAR RNA 编辑（A→I）

## 是什么

不靠外源蛋白，只投一段**招募 RNA（arRNA / guide RNA）**，把细胞**内源**的 ADAR（Adenosine Deaminase Acting on RNA）酶招到目标转录本上：

```
arRNA（带一个故意的 A:C 错配）  +  内源 ADAR（识别双链区的 A）
      → ADAR 把 A 脱氨成 I（肌苷）
      → 核糖体 / 剪接体把 I 读作 G
      → 相当于在不碰 DNA 的前提下，把一个 A 临时改成 G
```

## 解决什么：从"关闭"到"改写"、从"不可逆"到"可逆"

| | Cas9 / 碱基编辑（DNA） | ADAR（RNA） |
|---|---|---|
| 对象 | DNA | RNA |
| 可逆性 | **永久** | 可逆（停药即恢复） |
| 外源蛋白 | 需要（Cas9 递送 + 免疫原性） | **不需要**（内源 ADAR） |
| 能做 | 敲除、敲入 | **修正点突变**、诱导外显子跳跃 |
| 监管风险 | 高（NTLA-2001 单例 AE 被叫停） | 相对低 |
| 持久性 | 终身 | 需重复给药（或用病毒载体长期表达） |

## 代表与最新

- **Wave Life Sciences**：WVE-006（AATD，Alpha-1 抗胰蛋白酶缺乏症），2026 年起加速与 FDA 沟通（来源为行业综述，**需复核**）
- **Korro Bio**：KRRO-110，同为 AATD
- 国内：**北京大学 / 昌平实验室 魏文胜团队 LEAPER 平台**

### ⭐ 2026 年最重的一篇：circ-arRNA 治 DMD（*Cell*，2026-06-10）

> Guo W, Tang H, Yi Z, et al. *Long-term reversal of Duchenne muscular dystrophy via circular arRNA-guided exon skipping in monkeys and humans.* Cell 2026-06-10. doi:10.1016/j.cell.2026.05.030

- 用**环状** arRNA（circ-arRNA）招募内源 ADAR，诱导 DMD 外显子跳跃，恢复抗肌萎缩蛋白
- **非人灵长类：单次 MyoAAV 给药 → 疗效维持 ≥1.5 年**，且未产生抗-dystrophin 免疫反应
- **首个人体研究：3 例 DMD 患儿单次给药**，高剂量组 dystrophin 达正常值约 2.06%，NSAA 最高提升 8 分（2 人达满分），安全性良好
- 机制是**双通道**：ADAR 依赖的 RNA 编辑 + ADAR 非依赖的剪接体位阻干扰

> **注意这是两个方向的一次合流**：ADAR（动作）+ circRNA（时间）叠在同一个分子上。
> 前沿方向之间不是互斥的，会互相组合 —— 判断一个新方向时，先问它补的是空间 / 动作 / 时间哪一格。

## ⭐ 计算切入点（这是本方向最硬的一块）

1. **编辑窗口建模**（最有价值）：ADAR 的编辑效率**极度依赖招募 RNA 的错配位置、双链长度、局部二级结构**。
   例如：目标 A 对面放 C 是标配，但两侧 ±1~±3 位的碱基身份会显著改变产率 —— **这天然是一个监督学习任务**（特征 = 序列 + 结构；标签 = 编辑率）。
2. **RNA-Seq 定量编辑率**：A→I 在测序上表现为 **A→G mismatch**（因为 I 被反转录成 G）。从比对结果里数特定位置的 A→G 比例 = **纯生信活儿，且需要严格的假阳性控制**（SNP、测序错误、比对偏好）。你已经做过 variant calling，这套做起来会很顺。
3. **脱靶编辑全转录组扫描**：同样 A→G mismatch，但要在全转录组范围找非预期编辑位点 —— 和 D5 的 GUIDE-seq 分析是**同一类问题**。

# 第三部分 · saRNA（小激活 RNA）

## 是什么

结构上跟 siRNA 几乎一样（也是双链、也要 Ago2 装载），但**guide 链作用的位置完全不同**：

| | siRNA | saRNA |
|---|---|---|
| 靶标区域 | mRNA 的 CDS / 3′UTR | **基因启动子附近 / 启动子相关转录本** |
| 复合体位置 | 胞质 | **细胞核** |
| 结果 | mRNA 降解（**下调**） | 招募转录激活复合体（RNAa，RITA 复合体：Ago2 + CTR9/PAF1C + RNA Pol II）→ **上调** |

> **一句链路**：saRNA 把 Ago2 带到**启动子附近** → 组装转录激活复合体 → **把基因打开**。

## 解决什么：方向反转

核酸药一直擅长"关掉"，但很多病需要的是"**补回来**"：

- 单倍剂量不足（haploinsufficiency）
- 想恢复抑癌基因 / 转录因子表达
- 需要在不改变序列的前提下调高某一通路

## 代表与现状（**置信度中等，需复核**）

| 药物 | 公司 | 靶点 / 适应症 | 状态 |
|---|---|---|---|
| **MTL-CEBPA** | MiNA Therapeutics | CEBPA（转录因子）/ 肝癌，联合索拉非尼 | **首个进入临床的 saRNA**（LNP 递送去肝） |
| **RAG-01** | Ractigen Therapeutics | 膀胱癌（**膀胱灌注**，局部给药） | I 期 |

> ⚠️ **整体判断**：saRNA 是四个方向里**临床成熟度最低**的一个（对比 AOC 已有 BLA、ADAR 已有 *Cell* 级人体数据）。
> 值得知道它在 SELEX 之外提供了一条"反方向"的思路，但**不建议在阶段三的项目里押它**。

### 别搞混：saRNA ≠ sa-mRNA

- **saRNA**（small activating RNA）= 双链小 RNA，**上调内源基因**
- **sa-mRNA**（self-amplifying mRNA）= 自扩增 mRNA，带**病毒复制酶**，是为了**少剂量**
  - 代表：Arcturus / CSL 的 **KOSTAIVE** —— 全球首个获批的自扩增 mRNA 疫苗（日本、欧盟）

## ⭐ 计算切入点

- saRNA 的靶点必须落在**转录活跃的启动子 / 近端区域** → 需要判定"哪些基因的启动子在目标细胞里真正在转录"
  ⇒ **CAGE / PRO-cap / GRO-seq / PRO-seq（新生 RNA 测序）数据分析** —— 这正好是转录组学那套东西，**你的主场**。
- 规则层面：saRNA 设计规则远比 siRNA 少公开的成熟 rule set，**这是一个数据稀疏但门槛合适的建模机会**（如果你手上正好有公司的启动子活性数据）。

# 第四部分 · circRNA（环状 RNA）

## 是什么

5′ 端和 3′ 端**共价闭合**形成环。

```
线性 mRNA：  5′cap —•—•—•—•— 3′polyA      ← 两端都是核酸酶的入口
circRNA：    5′—•—•—•—•—3′
                └──────┘ 闭合，没有游离末端
```

**没有游离末端 ⇒ 天然抗外切酶降解**（RNase R 也切不动）。

## 解决什么：把"表达时长"从小时拉到天

| | 线性 mRNA | circRNA |
|---|---|---|
| 表达时长 | 24–48 h | **7–14 天**（公开综述口径，**需复核**） |
| 是否需 cap | 需要（翻译起始） | 不需要 → 用 **IRES** 或 **m6A** 驱动帽非依赖翻译 |
| 是否需 poly(A) | 需要 | 不需要 |
| 给药频率 | 频繁 | 大幅下降 |

同时它也是 **arRNA 的理想载体形式**（见上面 *Cell* 论文，用 circ-arRNA 才撑到了 1.5 年）。

## 三个必须知道的工程难点

1. **环化效率与"疤痕"**：主流方法是 **PIE（permuted intron-exon）自剪接**，会在环上留下一段**外显子疤痕序列** —— 疤痕长度和序列本身就是设计变量
2. **免疫原性争议**：环状 RNA "天然低免疫原性"是有条件的。**体外转录产物若残留双链 RNA / 缺刻 RNA 杂质，会强烈激活 RIG-I / MDA5**。纯度决定结论（这和 D4 学的 m1Ψ 纯化问题是同一类教训）
3. **翻译起始效率**：没有 cap，全靠 IRES 或 m6A —— **这直接就是一个序列设计优化问题**

## 代表公司（**近两年有收缩/转向报道，务必查最新状态**）

Orna Therapeutics（oRNA，重心转向 in vivo CAR-T）、Laronde / Flagship（eMaC）、Chimerna，国内有环码生物（CirCode）、吉赛生物等。

> 诚实地说：**circRNA 是四个方向里"公司口径"和"实际进展"差距最大的**。
> 建议是：把它当**技术要素**记住（任何想延长 RNA 半衰期的项目都可以用），不要当作一个**赛道**去跟。

## ⭐⭐ 计算切入点 —— 这是四个方向里跟你最对口的一个

circRNA 的检测**只能靠生信**：

| 关键问题 | 生信解法 |
|---|---|
| 怎么证明它是"环" | 找 **BSJ（back-spliced junction，反向剪接点）reads** —— 跨越"尾巴→头部"接点的读段是环状的唯一直接证据 |
| 怎么富集 | 实验侧 **RNase R 处理**（消化线性 RNA）+ 测序；分析侧要建模 RNase R 效率偏好 |
| 怎么定量 | BSJ reads 数 / 总 reads；需要区分线性转录本的**反向剪接噪音** |
| 常用工具 | **CIRCexplorer2、find_circ、CIRI2、DCC、circRNA_finder** |

> 你已经处理了十年 RNA-Seq 数据。**circRNA 鉴定本身的门槛对你几乎为零**，
> 真正的价值在于：把这个能力放到"我们的 RNA 药物/工具 RNA 是否成环、表达多久"这个**应用场景**里 —— 这个组合很少有人同时具备。

空间 → AOC；时间 → circRNA；动作 → ADAR + saRNA。

<details>
<summary><b>2. AOC 为什么全行业都用 TfR1？它的代价可能是什么？</b></summary>

TfR1 在骨骼肌、心肌表达高，且本来就在执行受体介导的铁摄取，**内吞效率高**；已有 JCR 的 pabinafusp alfa（日本获批）验证 TfR1 递送可行。

代价／风险：① 抗体本身带来的**免疫原性**和**Fc 效应**（与 FcRn 相关的再循环会改变 PK）；② TfR1 参与铁代谢，**干扰铁稳态**是潜在毒性；③ 偶联使分子量从 ~17 kDa 涨到 **~150 kDa**，PK 行为完全不同；④ CMC 复杂度远高于裸 siRNA（偶联效率、DAR 均一性、连接子稳定性）。

</details>

<details>
<summary><b>3. 从 donidalorsen 的分子式 C296H415N83O151P20S15Na20 能读出什么结构信息？</b></summary>

- **P20 → 20 个核苷酸**（20-mer）
- **S15 → 15 个硫代磷酸**（20-mer 共 19 个连接，故最多 19 个 PS；此处刻意只做 15 个，**留了 4 个天然磷酸二酯** —— 对比 Nusinersen 的 17/17 全长 PS）
- Na20 → 20 个钠离子（对应磷酸骨架，不要当成核苷酸数）
- 再结合 label 的完整化学名 → **5′-翼 5 个 2′-MOE + 中间 10 个 DNA gap + 3′-翼 5 个 2′-MOE = 标准 5-10-5 gapmer**；gap 内含 m5C

</details>

<details>
<summary><b>4. 三款 2025 新药靶点、疾病、模态都不同，唯一相同的是什么？这个事实说明了什么？</b></summary>

唯一相同的是**递送：GalNAc（都靶向肝细胞 ASGPR）**。

说明：**分布团已经被平台化、标准化**，新药开发的变量收敛到了"序列（药效团）"这一件事上。
因此监管部门、CMC、临床开发路径都可以复用，这就是一年能批三款的原因，也是为什么平台型公司喜欢"管线即复制"。
反过来也说明：**只要你的靶点不在肝/肝脏之外，这套底盘就完全帮不上忙** —— 这正是 AOC 存在的原因。

</details>

<details>
<summary><b>5. ADAR 编辑相对 Cas9 编辑的最大优势是什么？这个优势在监管层面意味着什么？</b></summary>

最大优势是**可逆 + 不需要外源蛋白**。

- 可逆：作用于 RNA，停药即恢复；**没有双链断裂**，没有永久性基因组改变，也没有"切错了永远留着"的问题
- 不需外源蛋白：免疫原性和递送负担大幅下降（这也是为什么可以用 AAV 长期表达 arRNA）

监管含义：参考 NTLA-2001 事件 —— **一个单例严重 AE 就足以让 450 多例 III 期被 FDA 临床搁置**。
不可逆模态的容错成本极高；ADAR 因为可逆，**风险画像更接近传统药物**，监管容忍度更高。
（但也要注意它的短板：持久性依赖给药或病毒载体长期表达。）

</details>

<details>
<summary><b>6. circRNA 在测序数据里唯一的直接证据是什么？为什么光凭"读段覆盖了环状区域"不能下结论？</b></summary>

唯一直接证据是跨越**BSJ（back-spliced junction，反向剪接点）**的读段 —— 即一条 read 的 5′ 部分比对到下游外显子、**"跳"回去**比对到上游外显子的那种"倒序"比对。

光凭覆盖度不能下结论的原因：同一个外显子组合，线性转录本也会产生 reads。要区分"真的成环"还是"线性转录本的可变剪接"，必须看**是否有 read 直接跨越那个首尾相接的接点**。
此外还需排除：模板转换造成的假 ***RT artifact***、基因组上相邻基因的 read-through、以及环状 RNA 数据库本身的注释错误。

</details>
