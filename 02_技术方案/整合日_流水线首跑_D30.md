## 任务 2｜ESC / ESC+ 模板化学的计算表示（30–40 min）

### 2.1 读材料（30 min，我已备好三篇）

1. **Mol Ther—Nucleic Acids 2020 GalNAc 综述**（主线最清晰）：STC→ESC→ESC+ 演化、5′-VP（免细胞磷酸化、效力 +10×）、Reversir 解药、Foster 等 NHP 单次给药 3 个月数据
   `https://www.sciencedirect.com/science/article/pii/S1525001620303051`
2. **GalNAc 缀合综述（PMC）**：ESC 专利原则四条（切割位点附近三连 2′-F、其余交替 F/OMe、双端 PS×2、5′ AU 偏好）+ 关键原话"**ESC 确切组成未公开**"
   `https://pmc.ncbi.nlm.nih.gov/articles/PMC5363494/pdf/main.pdf`
3. **中文综述（pibb 2018）**：DV18 具体模式逐位标注 + ESC+ 的 GNA 放反义链第 7 位降 seed 脱靶
   `https://www.pibb.ac.cn/pibbcn/article/html/20180249`

**学习问题（读时带着）**：STC→ESC→ESC+ 三代各解决什么？（剂量↓280×：vutrisiran ESC vs revusiran STC；GNA 热去稳定降 seed 脱靶——和 D25 热力学不对称、D26 pos19 冲突同一条机理线）

### 2.2 编码设计题（速查表开 §2.5，为 W5 脚本铺路）

把修饰模式变成**可计算表示**，草案（自己改）：

```python
mod = {
    "sense":   "FOMFOMFOMF...",     # 每位一个糖标记：F=2'-F, O=2'-OMe, G=GNA, D=DNA
    "guide":   "OMFOMFOMF...",
    "ps":      [(0,1), (1,2), ...],  # PS 位点（碱基间连接，0-based）
    "ends":    {"guide5": "VP"},    # 端基：VP=5'-vinyl phosphonate
    "length":  {"sense": 21, "guide": 23},
}
```

检验标准：用这个 schema 能不能**无歧义重放出 vutrisiran / inclisiran 的修饰描述**？不能 → 缺字段。（D14 教训的延续：字母表必须含修饰字母，解析器别假设纯 ACGU。）

⚠️ 事实纪律：ESC 确切组成**未公开**（综述原文），专利原则只作算法素材不当作已上市药物的确切配方；Foster 原始文献（"Advanced siRNA designs further improve in vivo performance…"，Mol Ther—Nucleic Acids）**年份卷期 🟡 待核**——今天顺路核掉。
