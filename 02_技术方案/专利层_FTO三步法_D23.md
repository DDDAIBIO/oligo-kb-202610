## 0. 今天的定位：三层概念先分清，再谈三步法

D18 把专利层扔进 C 级（只能靠人），这话对一半。**读权项是法律活，但"我的序列有没有被别人的序列表覆盖"是纯生信活。**
今天要拿到的，就是这条边界上的那 10%：

> 专利层你不需要变成专利代理人，
> 你需要能**自己先跑一遍序列筛查**，然后拿着"命中清单 + 特征矩阵"去找代理人，
> 而不是把一叠序列丢过去问"这个能卖吗"。

先分清三件常被混为一谈的事（混了就白干）：

| 概念 | 问的问题 | 结论不好会怎样 |
| --- | --- | --- |
| **专利性**（novelty / inventive step） | 我能不能拿到专利？ | 拿不到，但**不影响你卖** |
| **FTO**（freedom to operate） | 我卖会不会踩别人的权项？ | 会被诉、被禁售、被索许可费 |
| **有效性**（validity） | 对手那件专利能不能被打掉？ | 打掉就自由，打不掉就得绕 |

⭐ 三者互相独立：**你可以拿到自己的专利，同时侵犯别人的专利**（改进型专利的经典困境）。
所以"D23 的 FTO"和"申请自己的专利"是两条线，今天只走 FTO。

## 1. 权利要求怎么读：只看独立权利要求，看"全部"技术特征

一条铁律（中国、美国、欧洲共通）：

> **保护范围由独立权利要求的技术特征共同限定**——被控产品必须**逐个**包含全部特征才算落入（全面覆盖原则 / all-elements rule）。
> **任何一个特征不满足，字面上就不落入。**

所以读专利的动作只有三步：**找独立权项 → 拆成特征清单 → 逐条对照我的分子**。

寡核苷酸专利的权项通常长这样（同一件专利里层层嵌套）：

| 类型 | 典型写法 | 覆盖范围的特点 |
| --- | --- | --- |
| **序列表型** | `SEQ ID NO: 1`（19–23 nt），或"与 SEQ ID NO: 1 具有至少 90% 同一性的序列" | 有同一性阈值时**范围远大于一条序列**（21-mer 的 90% 允许 2 个碱基不同） |
| **修饰型** | "其中每个核苷酸独立地为 2′-OMe 或 2′-F，且至少 8 个连续核苷酸为 PS 键" | 决定"改化学能不能绕开" |
| **偶联/递送型** | "与三价 GalNAc 配体共价连接" | 常是基础专利，最难绕 |
| **用途型** | "用于治疗 hATTR 多发性神经病" | 用途限定，换适应症可能不落入 |
| **组合物/制剂** | 载体、缓冲体系、浓度范围 | 制剂专利，量产时才关键 |

两条反直觉的结论，记住能省很多钱：

- **序列相同 ≠ 侵权**：权项写死"2′-MOE 全修饰 gapmer"，你拿同一段序列做成 2′-OMe/F 的 siRNA，字面上不落入（但要过等同原则这一关）。
- **序列不同 ≠ 安全**：权项用"≥90% 同一性"或"严格条件下杂交"界定时，你改了 2 个碱基仍在范围内。

**等同原则**（doctrine of equivalents）是第二道网：手段、功能、效果实质相同，且本领域技术人员无需创造性劳动即可联想到 → 仍可能侵权。
中国司法实践的四要件就是这个（手段/功能/效果/显而易见性），🟡 具体条文与最新司法解释动手前回查。
**实务含义**：绕开设计不能只改"无关紧要的一个碱基"，那正是等同原则最爱抓的情形。

## 2. ⭐ 三步法（今天的骨架）

| 步 | 动作 | 产出物 | 谁能做 |
| --- | --- | --- | --- |
| **① 拆** | 把每件相关专利的**独立权项**拆成特征清单：序列（含同一性阈值）/ 长度范围 / 修饰模式 / 偶联配体 / 递送 / 用途 | 特征清单表（1 专利 × N 特征） | 人（代理人 + 你） |
| **② 比** | 建"特征 × 候选分子"矩阵，每格判：落入 / 不落入 / 等同风险 | **特征矩阵**（唯一能拿去决策的东西） | 你（分子信息在你手上） |
| **③ 定** | 四条路：设计绕开 / 谈许可 / 挑战无效 / 换靶点 | 决策建议 + 时间成本 | 管理层 |

**② 比 的判法（关键细节）**：

- 先看**序列层**：我的 21-mer 是否落在某条 `SEQ ID NO` 或"≥90% 同一性"范围内 → 这一层可以全自动（§3）。
- 再看**修饰层**：权项限定的修饰模式我是否**全部**满足。少一个特征（比如它要求至少 8 个 PS，我只用 4 个）→ 字面不落入。
- 最后看**用途层**：同一分子换适应症，可能不落入用途限定型权项——但**物质权项（序列/修饰）不受用途限制**，别指望靠换适应症绕物质专利。

**③ 定的成本排序**（实务经验，非事实陈述）：设计绕开 < 谈许可 < 挑战无效（无效程序 1–3 年，且输了专利还在）。

## 3. A 级那 10%：专利序列检索（你的主场）

### 3.1 关键事实：专利序列确实在 GenBank 里

NCBI 的 GenBank 有一个专门的 **PAT 分区**，收录专利里公开的核酸/蛋白序列，accession 形如
`pat|US|8xxxxxx|SEQ ID NO:1` 一类 ✅（GenBank 专利分区是长期存在的公开数据）。

**这意味着什么**：你手上那条 21-mer，**可以直接 BLAST 到专利序列库**，看有没有被某件专利的序列表覆盖。
这是整个 FTO 流程里唯一能全自动、能批量、能今天就跑的一步——也正好是你的技能。

### 3.2 短序列 BLAST 的三个参数坑

| 坑 | 后果 | 正确做法 |
| --- | --- | --- |
| 默认 `word_size=11` | 21-mer 也许能跑，但 12–15 nt 的 motif 完全无命中 | `-task blastn-short -word_size 7` |
| 默认 E-value 阈值 | 短序列的 E 值天然偏大，漏掉真命中 | 放宽 `-evalue 10`（短序列看 identity 和覆盖度更可靠） |
| 只查 nt 库 | nt 主库与 PAT 分区混在一起时结果噪声大 | 明确限定库（PAT 或 nt 里过滤 `pat|`），并记录库版本日期 |

### 3.3 检索入口清单（v0，够用）

| 入口 | 用途 | 备注 |
| --- | --- | --- |
| Google Patents | 全文 + 权项浏览、同族合并 | 适合读权项，不适合批量序列查 |
| Espacenet / WIPO Patentscope | 同族（INPADOC family）去重 | 一件发明多国申请，按同族看省 80% 时间 |
| CNIPA（中国及多国专利审查信息查询） | 中国同族、审查状态、法律状态 | 中国市场的 FTO 必须查中国同族 |
| **NCBI BLAST（PAT 分区 / nt）** | ⭐ 序列级筛查 | 你的日常工作流，今天就能跑 |
| Lens.org / 商业库 | 交叉验证、引证网络 | 有预算再说 |

**CPC 起手分类号**：`C12N15/113` = 调控基因表达的非编码核酸（反义寡核苷酸、siRNA 一类）✅ 这是最直接的入口，
再叠加 `A61K31/713`（siRNA 类药品）一类做辅。🟡 分类号表会修订，动手前用 CPC 官网确认当期定义。

### 3.4 时间维度：20 年不是唯一答案

- 基础期限：**自申请日起 20 年** ✅（TRIPS 通行；中国《专利法》第 42 条第一款同）
  ⚠️ **不是自优先权日起**——优先权只影响"现有技术"的时间界线（判断新颖性/创造性），**不改变专利期限**。这是最常算错的一处。
- 但中国自 2021-06-01 起有**药品专利期限补偿（PTE）**：对在中国获得上市许可的新药相关发明专利，应专利权人请求给予补偿，**补偿 ≤ 5 年，且新药批准上市后总有效专利权期限 ≤ 14 年** ✅（《专利法》第 42 条第三款，2020 年修正、2021-06-01 施行；不溯及 2021-05-31 前已获上市许可的新药）。
- 实务含义：**"申请日 + 20 年"多数时候仍会算错到期日**。看法律状态时同时看：是否有 PTE、是否有授权过程中延迟的期限补偿（第 42 条第二款）、是否有年费欠缴导致的提前终止。

## 4. 现实感：这是一个专利丛林，不是一片空地

寡核苷酸（尤其 GalNAc-siRNA）领域的现状：

- **基础层**（修饰模式、GalNAc 偶联、递送）被少数先驱公司大量占位，后来的玩家基本都要谈许可或做差异化修饰；
- **序列层**（具体靶序列）相对拥挤但可绕——只是绕开要回到 D20/D21 重扫窗口；
- 历史上有大量 LNP / 递送相关诉讼与交叉许可，具体案件与判决状态 🟡 **本笔记不引具体案号与金额**（未逐条核实），需要时单独做一次带日期的事实核查。

> 结论性的判断（工程判断，非事实陈述）：**FTO 在核酸药里不是"最后一道手续"，而是设计早期的约束条件**——
> 一个好位点如果被物质专利覆盖，它的价值直接归零，和"打不到"是同一量级的否决项。

## 5. 计算切入点：`claim_hit.py` 规格

承接 D22 的镜像思路，FTO 层也有一个可立即动手的小工具：

**输入**：候选分子（guide 序列 + 修饰模式描述，如 `21nt, 2'-OMe/F partial, 3xGalNAc`）
**输出**：命中清单（专利号 / SEQ ID NO / identity / 覆盖度 / 库版本日期）+ 待人工读的权项清单

v0 三步（纯生信，不碰法律判断）：

1. **序列筛查**：`blastn -task blastn-short -word_size 7 -evalue 10` 对 PAT 分区 → 命中即"序列表覆盖"候选；
2. **同一性扩展**：对命中的 `SEQ ID NO`，反向检查"我的序列 vs 该序列"的 identity（处理"≥90% 同一性"型权项）——阈值从权项里读，不自己定；
3. **特征打标**：把权项文字里的修饰/偶联要求做成字段（长度范围、同一性阈值、PS 个数、2′ 修饰种类、偶联类型），人工填一次，之后与本分子逐项比 → 出特征矩阵。

v0 纪律（沿用 D21/D22）：**命中 ≠ 侵权**。工具只负责"缩小要读的范围"，任何"落入/不落入"的结论都不由脚本给出，
必须进特征矩阵 + 人（代理人）复核。**别让脚本背法律结论，这是这行的红线。**
