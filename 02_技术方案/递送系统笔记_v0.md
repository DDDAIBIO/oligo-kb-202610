## 0. 为什么递送要单独占一周

启动周建立了：`核酸药 = 药效团（打谁）+ 分布团（去哪）+ 作用机制（做什么）`。
**递送系统就是分布团的全部。** 而且本周要把它再往前推一层：

### ⚠️ 更正记录 C5：D7「只有偶联层改分布」这个说法不够

D7 的化学修饰四层里写了「只有偶联层改分布，上三层改成药性不改靶点」。本周拆完 Patisiran 后需要修正：

| 功能 | 可用手段 1 | 可用手段 2 | 可互换 |
|---|---|---|---|
| **去哪（分布）** | 偶联配体（GalNAc / 抗体） | **载体（LNP）** | ✅ 二选一或叠加 |
| **活多久（抗核酸酶）** | 化学修饰（PS / 2′-OMe / 2′-F） | **载体包封** | ✅ 见下 |

**证据**：Patisiran 分子式里 **S = 0，完全没有 PS**——ASO 靠 17/17 全长 PS 扛核酸酶，它靠 LNP 包封扛。
所以 D7 那句话应改写为：

> **化学修饰与递送系统之间存在功能重叠，二者可互相替代，也可互相补偿。**
> 拿到一款药，第一件事是问：**它的"保护"是谁做的、"导航"是谁做的？**

这个判断会直接决定后面所有设计选择（要不要加 PS、能不能皮下、要不要预处理）。

## 1. 三条递送路线与选择树

| 路线 | 做法 | 代表药 | 能到哪 | 代价 |
|---|---|---|---|---|
| **A. 裸化学修饰** | 只靠 PS / 2′修饰，无载体无配体 | Nusinersen（鞘内）、Fomivirsen（眼内，已撤） | 只能是**局部给药的隔室**（CSF、玻璃体） | 全身给药会被快速清除 |
| **B. 配体偶联** | 共价连 GalNAc（或抗体=AOC） | Inclisiran、Vutrisiran、Fitusiran、Plozasiran… | **肝细胞**（GalNAc）；AOC 可及肌肉等 | 受限于受体表达谱 |
| **C. 纳米载体** | LNP 包封 | Patisiran、Spikevax、NTLA-2001 | 主要肝（ApoE 被动）+ 局部注射部位 | 免疫原性、需预处理、CMC 重 |

**选择树（简化）**：

```
目标细胞在肝（肝细胞）？ ── 是 ──▶ GalNAc 偶联（首选，皮下、无需预处理）
        │
        否
        ▼
能否局部给药（CSF / 眼 / 吸入 / 瘤内）？ ── 是 ──▶ 裸修饰 + 局部注射
        │
        否（需全身给药到肝外）
        ▼
   ┌─────────────────────────────┐
   │ 这就是行业的开放难题          │
   │ 当前手段：AOC（抗 TfR1 等）  │
   │          SORT-LNP（改配方）  │
   │          配体偶联新受体       │
   └─────────────────────────────┘
```

> ⭐ 记住这张图：**"肝外递送"里真正已获临床验证的，几乎全是"换给药途径"，不是"靶向技术"。**
> 鞘内 = 绕过血脑屏障，玻璃体 = 直接打进眼，都不是"精确制导"。

## 2. 路线 B：GalNAc–ASGPR（肝靶向的黄金标准）

### 机制

1. **ASGPR**（去唾液酸糖蛋白受体）在肝细胞表面**高表达**，天然功能是清除血液中末端暴露半乳糖的糖蛋白。
2. 把 **三个 GalNAc 残基**共价连到 siRNA 上（Vutrisiran label 明文写 "three N-acetylgalactosamine residues"）→ 被 ASGPR 识别。
3. 受体介导内吞 → 进入肝细胞 → siRNA 装载 RISC。
4. 受体可**再循环**，不会一次性耗尽。

### 为什么是三价

单价 GalNAc 亲和力不足；**多价效应**使三价结合与内化效率呈数量级提升（具体倍数 ⚠️ 待核，不要写成确定数字）。

### 已上市药的规模

启动周对比表里 9 款成功药中，GalNAc 偶联占绝大多数（Inclisiran、Vutrisiran、Fitusiran、Plozasiran、Givosiran、Lumasiran…），2025 年三款新药**唯一共同点就是 GalNAc**。

> **一次底盘 + 反复 repurpose** —— 这就是平台化的含义，也是"肝外靶点完全吃不到红利"的原因。

### 局限

- **只有肝细胞**。库普弗细胞、肝星状细胞打不到（它们不表达或低表达 ASGPR）。
- 需要皮下/静脉进入循环，且依赖受体表达量 —— 受体下调或竞争会失效。
- 血浆蛋白结合高（Vutrisiran 80%，且**浓度依赖**：0.5 µg/mL 时 78% → 50 µg/mL 时 19% → 提示结合位点会饱和）。

## 3. 路线 C：LNP——四组分与"表观 pKa"

### 四组分（以 Patisiran 每 mL 实测量为例）

| 组分 | 作用 | Patisiran 量 |
|---|---|---|
| **可电离脂质**（MC3） | 主角：包封 + **内体逃逸** | 13.0 mg |
| **胆固醇** | 填充堆积缺陷、稳定颗粒、**助逃逸** | 6.2 mg |
| **辅助磷脂**（DSPC） | 界面单分子层强度、减少泄漏 | 3.3 mg |
| **PEG-脂质**（PEG2000-C-DMG） | 亲水空间位阻、防聚集、**延长循环** | 1.6 mg |

- 脂质/RNA 质量比 ≈ **12 : 1**（Patisiran）vs ≈ **20 : 1**（Spikevax mRNA）
  → 载荷越长越难包，需要的脂质越多。
- PEG 是**双刃剑**：过量阻碍细胞摄取与逃逸，不足则胶体不稳、清除加快。

### ⭐ 表观 pKa：本节最容易被讲错的一点

| 可电离脂质 | **分子（3°胺）pKa** | **表观 pKa（LNP 中，TNS 法）** | 用途 |
|---|---|---|---|
| DLin-MC3-DMA | 9.46 | **6.44** | Onpattro（siRNA，IV） |
| SM-102 | 8.96 | **6.75** | Spikevax（mRNA 疫苗，i.m.） |
| ALC-0315 | 9.6 | **6.09** | Comirnaty（mRNA 疫苗，i.m.） |

**关键理解**：

1. **两个数差了近 3 个 pH 单位。** 表观 pKa 是**配方（LNP）的属性**，不是自由分子的属性——疏水环境、脂质间相互作用共同决定。文献原话："pKa is an emergent LNP property rather than an intrinsic small-molecule constant"。
2. **生理 pH 7.4 下基本中性** → 低毒、少非特异结合；**内体 pH 5.5–6.5 时质子化** → 带正电 + 锥形几何 → 破坏内体膜 → 释放载荷。
3. **"黄金区间"不是唯一值**：siRNA 肝递送约 **6.2–6.5**；肌肉注射疫苗优化到 **~6.6–6.9**。
   → 同一个参数，**因给药途径与目标组织而异**。看见"pKa 应该 6.4"这种话要追问：什么途径、什么细胞。

### 内体逃逸：行业最大瓶颈

> 文献表述：**仅 1–2%** 的 siRNA 能有效从内体逃逸，且只发生在具有早/晚内体共同特征的特定区室。

D4 记的"~2%"本周得到确认。**这意味着 98% 的载荷是白送的**——谁解决逃逸，谁就是下一个平台。

### 脂质演化（MC3 → SM-102 / ALC-0315）

| 变化 | 带来什么 |
|---|---|
| 支化尾 + 顺式双键 | 锥形几何 → 膜融合性↑ → 逃逸↑ |
| **酯键**替代乙缩醛键 | 可生物降解 → 肝毒性↓、耐受性↑ |
| 尾长约 9–14 碳 | 平衡包封效率与逃逸 |
| 小头基 + 高支化尾 | 进一步提升逃逸 |

### ⭐ LNP 去肝，是"主动靶向"吗？

**不是。** 静脉注射后 LNP 吸附血浆 **ApoE** → 被肝细胞 LDL 受体识别 → 被动富集于肝。
对比 GalNAc 是主动识别 ASGPR。

> 这是两类递送的本质区别：**一个是精确制导，一个是靠血液蛋白"顺路带过去"。**
> 也解释了为什么改配方（**SORT**：Selective ORgan Targeting，加入第五种脂质）就能把 LNP 的器官倾向从肝挪到脾/肺——因为它本来就没有锁定肝。

## 4. 天然对照：TTR 双药（本周最佳案例）

> 同靶点 TTR、同公司 Alnylam、同疾病 hATTR，**唯一变量 = 递送方式**。
> 完整数据表见 `99_原料/Vutrisiran_Amvuttra_label_要点.md` §6。

| 维度 | **Patisiran（LNP）** | **Vutrisiran（GalNAc）** |
|---|---|---|
| 途径 | IV 输注 80 min | 皮下注射 |
| 间隔 / 年次数 | Q3W / 17.3 次 | Q3M / **4 次** |
| **年剂量** | ≈ 364 mg | **100 mg** |
| **必需预处理** | **激素 + 抗组胺 + 退热** | **无** |
| 抗核酸酶 | LNP 包封（**0 PS**） | 化学修饰（**6 PS**） |
| 血浆蛋白结合 | ≤ 2.1% | 80%（浓度依赖） |

**三条结论**：
1. 递送方式不是调参，它**重新定义了整个产品**（剂量、频次、预处理、剂型、CMC）。
2. GalNAc 不是免费午餐——丢掉 LNP 包封后，PS 从 0 加回 6。
3. ⚠️ 这不是头对头临床试验（不同年代、不同试验），**只能作工程学对照，不能写成"疗效优于"**。

## 5. 肝外递送：现状矩阵

| 目标组织 | 已临床验证的手段 | 代表 | 本质 |
|---|---|---|---|
| **肝细胞** | GalNAc SC / LNP IV | 9 款 GalNAc 药、Onpattro | ✅ 已解决 |
| **CNS** | **鞘内注射（IT）** | Nusinersen、Tofersen | 绕过 BBB，非靶向 |
| **眼** | **玻璃体内注射** | Izervay（Pegaptanib 已撤） | 局部 + 免疫豁免 |
| **肺** | 吸入 / 雾化 | 在研 | 局部 + 黏膜屏障 |
| **肌肉 / 心肌** | **AOC（抗 TfR1）** | AOC 在研（del-desiran ⚠️ 待核） | 受体介导，最接近"真靶向" |
| **免疫细胞** | 抗 CD 抗体偶联 / in vivo CAR-T | 在研 | 热点，未成药 |
| **肿瘤** | LNP / 配体 | 多处在研 | EPR 效应存疑 |

> ⭐ **判据**：判断一个"肝外递送突破"的含金量，先问——
> **它是换了给药途径（局部），还是真的实现了全身给药后的组织选择性？**
> 前者是工程优化，后者才是平台级突破。

## 6. 免疫原性：从"知道有 TLR"到"能写成规则"

### 受体 → 触发条件

| 传感器 | 识别什么 | 在本领域何时被触发 |
|---|---|---|
| **TLR3** | 长 dsRNA | IVT 反应产生的 dsRNA 杂质 |
| **TLR7 / TLR8** | ssRNA，**GU-rich / U-rich** | 未修饰 RNA、特定序列基序 |
| **TLR9** | 未甲基化 **CpG DNA** | ⭐ **ASO 的 DNA gap 里就可能含 CpG** |
| **RIG-I** | **5′-ppp / 5′-pp** dsRNA | 未加帽的 IVT 产物 |
| **MDA5** | 长 dsRNA | 同上 |
| **PKR** | dsRNA | 磷酸化 eIF2α → **翻译关停** |
| **OAS / RNase L** | dsRNA | 全局 RNA 降解 |
| **补体（替代途径）** | PS-ASO（抑制因子 H） | ⭐ PS 数量过多 |
| **抗 PEG 抗体 / ABC** | PEG | 重复给药 → 加速血液清除 |

> 这组对应解释了 D4 的两个设计：**m1Ψ 全替代 U**（躲 TLR7/8 + RIG-I → 不触发 PKR 关停翻译）和 **加帽**（躲 RIG-I）。

### ⭐ 可计算特征清单（D16 脚本的输入规格）

把上面变成能从序列算出来的东西：

| # | 特征 | 对应风险 |
|---|---|---|
| 1 | **CpG 二核苷酸计数**（尤其 DNA 区域） | TLR9 |
| 2 | **GU-rich / U-rich 基序**（如 `GUCCUUCAA`、`UGUGU`） | TLR7/8 |
| 3 | **AU-rich 元件**（`AUUUA` 重复） | 炎症/不稳定 |
| 4 | 5′ 端三磷酸（IVT 产物，非序列特征，来自工艺） | RIG-I |
| 5 | **预测双链区长度 / dsRNA 长度** | TLR3、MDA5、PKR |
| 6 | **GC 含量、Tm**（含修饰 ΔTm 修正） | 稳定性、二级结构 |
| 7 | **发夹 / 自二聚体** | 聚集、免疫激活、RISC 装载受阻 |
| 8 | **PS 数量与分布** | 补体激活、蛋白结合、肝蓄积 |
| 9 | 聚嘌呤 tract / G4 倾向 | 非特异蛋白结合 |

> **这张表是后面所有 ML 模型的特征层雏形**（第 10–11 周的 OpenVaccine / 效力建模都从这里长出来）。
> 本周先让它在 D16 里变成能跑的代码。

## 8. 自检（合上资料能答出来才算过关）

<details>
<summary><b>第 1 题</b>：Patisiran 完全没有 PS（S=0），为什么不会被核酸酶秒掉？这对 D7「只有偶联层改分布」的结论意味着什么？</summary>

因为它 >95% 与脂质复合物结合，被 LNP 包封保护；ASO 靠 17/17 全长 PS 达到同样目的。
→ 说明**化学修饰与递送系统的功能可互换**，D7 的结论需修正为 C5。
</details>

<details>
<summary><b>第 2 题</b>：MC3 的分子胺 pKa 是 9.46，却说它"表观 pKa 6.44"。差在哪？哪个决定药效？</summary>

表观 pKa 是**LNP 配方整体**的属性（TNS 法测表面可质子化脂质），不是自由分子属性，差约 3 个 pH 单位。
决定药效的是**表观 pKa**——它决定生理 pH 下是否中性（毒性）与内体 pH 下是否质子化（逃逸）。
</details>

<details>
<summary><b>第 3 题</b>：LNP 静脉注射后主要去肝，这是主动靶向吗？</summary>

不是。靠吸附 ApoE → LDL 受体识别 → 被动富集。
证据：改配方加 SORT 脂质就能把器官倾向挪走，说明它本就没锁定肝。
</details>

<details>
<summary><b>第 4 题</b>：GalNAc 为什么只能打肝细胞？已上市药里它有多普遍？</summary>

因为配体识别的 ASGPR 只在肝细胞高表达（库普弗细胞/肝星状细胞打不到）。
9 款成功药中绝大多数是 GalNAc；2025 年三款新药唯一共同点就是它。
</details>

<details>
<summary><b>第 5 题</b>：Vutrisiran 血浆 t½ 只有 5.2 天，为什么能 3 个月打一针？</summary>

**PK/PD 脱耦**——血浆里的药早就没了，但它已在肝细胞里装载进 RISC，RISC 库周转慢 → 药效持续。
同 Inclisiran（血浆 t½ 9 小时，给药间隔 6 个月）。这是整个领域"为什么给药间隔这么长"的统一答案。
</details>

<details>
<summary><b>第 6 题</b>："肝外递送"里已获临床验证的手段，本质是什么？怎么判断一个"突破"的含金量？</summary>

本质是**换给药途径做局部给药**（鞘内、玻璃体、吸入），不是全身给药后的组织选择性。
判断标准：问它是换了途径，还是真的实现了全身给药的组织靶向。后者（AOC、SORT-LNP）才是平台级。
</details>
