## 0. 一句话定位

`scan_sites` 回答的是"**这一段能不能被打**"（可及性、区室、SNP）。  
`siRNA_design` 要回答的是"**这一段里，哪 21 个碱基最可能真的把 mRNA 切掉**"。

两者的关系不是替代，是**串联**：位点层先粗筛出可及区段 → 序列层在区段内枚举 21-mer 并打分 → 脱靶层再过滤。**链条是乘的，任何一层归零，全链条归零**——这是 W3 的总结论，本周开始把它变成代码。

## 1. 先定证据级别：这套规则是什么分量的东西

| 项    | 事实                                                            |
| ---- | ------------------------------------------------------------- |
| 出处   | Reynolds A. et al., *Nature Biotechnology* 2004, 22:326–330 ✅ |
| 样本   | **2 个基因、180 条 siRNA** 的系统筛选 ✅（文献一致引用）                         |
| 验证   | 按规则挑 30 条，**29 条有效** ✅（原文自述，也是二手文献最常引的数字）                     |
| 证据性质 | **单实验室、单细胞系、小样本 → 先验（prior），不是判决（verdict）**                   |

⚠️ 这条比规则本身重要：29/30 是**精心挑过的验证集**上的成绩，不是"任意基因任意位置 96.7% 有效"。规则的作用是**把命中率从随机水平抬上去**，不是保证沉默。任何"按规则设计所以一定有效"的说法都是误用。

## 2. 八条判据（原文计分制，逐条带物理意义）

> 编号约定：**sense 链 5′→3′，第 1–19 位**（不含 3′ 的 2 nt 突出端）。这是全局约定，全周不得混用。

| # | 判据                          | 计分                   | 物理意义（为什么这条能预测活性）                                                                              |
| - | --------------------------- | -------------------- | --------------------------------------------------------------------------------------------- |
| 1 | GC 含量 **30–52%**            | +1                   | 过高 → 双链过稳、解链慢；过低 → 结合弱、易非特异                                                                   |
| 2 | sense **15–19 位至少 3 个 A/U** | **每个 A/U +1（最多 +5）** | ⭐ **热力学不对称性**：sense 15–19 = antisense 1–5，此处 A/U 多 → 反义链 5′ 端更弱 → **AGO2 优先装载反义链**。八条里机理最硬的一条 |
| 3 | 无内部重复（内部二聚体 Tm* < 20 °C）    | +1                   | 自身折叠/发夹会抢走与 RISC 的结合，等效降低有效浓度                                                                 |
| 4 | sense **19 位 = A**          | +1                   | 3′ 端偏好；与装载方向、解链起点相关                                                                           |
| 5 | sense **3 位 = A**           | +1                   | 5′ 端附近偏好，影响 AGO2 对 5′ 磷酸的结合几何                                                                 |
| 6 | sense **10 位 = U**          | +1                   | 10 位正对 **AGO2 催化中心切割位点**（靶 mRNA 在 10/11 之间被切），此处 U 有利于切割构象                                    |
| 7 | sense **19 位非 G/C**         | **−1**               | 与第 4 条部分重叠（A19 必然满足）；G/C 在此处显著降活性                                                             |
| 8 | sense **13 位非 G**           | **−1**               | G13 抑制切割（切割位点邻近区域过稳）                                                                          |

**入选阈值：总分 ≥ 6**（上限 10 分：1+5+1+1+1+1 = 10，罚分另减）。  
🟡 待核：原文措辞是 "score of 6 defines the cutoff"，"≥6" 还是 ">6" 需回 PDF 确认；脚本先按 **≥6** 实现并写进注释。

### 2.1 三条容易被忽略的坑（今天就该发现）

1. **判据 4 与判据 7 重叠**：A19 成立时"无 G/C19"自动成立 → 计分对同一位置**罚一次、奖一次**，净效果是"非 A 的 19 位"被扣分。这不是 bug，是原文计分制的粗糙之处，**写脚本时要在注释里标出来**，否则 review 时会被当成自己算错。
2. **判据 2 与判据 4 也重叠**：19 位在 15–19 窗口内，A19 同时给判据 2 加分。
3. **判据 2 是唯一按"个数"计分的**（0–5 分），其余都是 0/1——所以总分里"15–19 位 A/U 富集程度"权重最大。这与"热力学不对称最重要"的机理判断一致，属于**计分设计与机理自洽**。

## 3. "十一条"还是"八条"？——一处口径更正（C10）

| 来源              | 条数                                      |
| --------------- | --------------------------------------- |
| 原文 Table 1（计分制） | **8 条**（上表）✅                            |
| 我们的总纲 §2.1      | 写"11 条"                                 |
| 二手综述常见写法        | 8 条 Reynolds + 3 条 Ui-Tei 混在一起 = "11 条" |

**判断**：总纲的"11 条"应是二手综述把 **Ui-Tei 2004** 的三条（反义链 5′ 为 A/U、19-mer 中 A/U 数、无 ≥9 nt GC 连续）并入后的计数。本周按 **Reynolds 8 条 + Ui-Tei 单列**处理——D26 正好要做三套规则对比，这个口径问题必须在那天收口。

## 4. 规则的边界：四个"不该用"的场合

| 场合                              | 为什么失效                                                            |
| ------------------------------- | ---------------------------------------------------------------- |
| **已化学修饰的候选**（2′-OMe / PS / LNA） | 修饰改变双链热力学与 AGO2 装载，**未修饰序列的分数不能直接外推**。这类序列的排序要靠实验或 ML 模型（W5+）    |
| **Dicer 底物 / 长 dsRNA**          | 规则是为 21-mer 化学合成 siRNA 归纳的，切割产物不是同一条                             |
| **要求"保证沉默"**                    | 规则只提高命中率。29/30 是最优场景，实际筛 10 条测 3 条有效是常态                          |
| **与可及性冲突时**                     | 规则不看二级结构，可及性不看序列偏好。**先可及性粗筛（D21），再规则打分**——不要用规则分去否决一个落在不可及区的高分候选 |

### §6.1 批改（2026-11-16）：1 ✅ / 4 🟡 / 3 ❌ ≈ 40%

> 两处"不知道"是诚实的——它们正好暴露了两个最该补的点（证据统计学、验证策略），都比装作会答强。

| 题 | 判 | 点评 |
| --- | --- | --- |
| 1 因果链 | 🟡 | 方向对（松端 → AGO2），但缺关键一跳：**为什么"5′ 端松"就能决定"这条链"被选**——因为引导链的 5′ 磷酸必须先进 MID 口袋被物理锚定，松端先解链，谁的 5′ 磷酸先被送到 MID 谁被锁成引导链。这条因果链你上午在 FAQ Q1 里已经完整推过一次——**答自检时没带上它，说明"追问时的理解"还没有变成"可随时调用的复述"**，这正是复测要解决的事 |
| 2 U10 | 🟡 | 只答"酶切的偏好位点"。补全：10 位正对 **PIWI 催化中心**，切割发生在靶 mRNA 的 10/11 位之间；此处 U 的偏好来自原文实证（切割位点附近不宜过稳，G:C 强配对会抑制刀位构象） |
| 3 重叠判据 | 🟡 | 找到 4/7 对，**漏了 2/4**——19 位同时在 15–19 窗口内，A19 既给判据 2 加分又给判据 4 加分。后果：同一位置被计分两次，"非 A 的 19 位"实际被双重惩罚。这是原文计分制的粗糙处，D28 脚本注释必须标出来，否则 review 时会被当成自己算错 |
| 4 总分上限 | ❌ | 不是"加权"——**八条等权、纯加和**。上限 10 = 1（GC）+ **5（判据 2 按个数计分，最多 5 分）** + 1（无内部重复）+ 1（A19）+ 1（A3）+ 1（U10），罚分（G/C19、G13）另减。判据 2 是唯一按个数计分的——这是"为什么它最重要"的量化体现 |
| 5 29/30 | ❌ | 不能外推，三个原因：① 规则本身从这 180 条归纳，30 条验证在**同一实验体系内 = 样本内验证**；② 验证集是按规则挑的（rule-selected），不是随机抽样；③ 单基因对、单细胞系。真实命中率显著低于 96.7%——这就是"先验不是判决"的量化含义。D22 的阴性结论三要素、D21 的"断言中间量"，和这里是同一个方法论家族：**训练集上算出的成绩不能当推广成绩** |
| 6 化学修饰 | ✅ | 对。补一句为什么：修饰改变双链热力学与 AGO2 装载几何，未修饰序列的分数不能外推（§4 第 1 条） |
| 7 可及性冲突 | 🟡 | **顺序对**（先可及性、再规则打分），但"摒弃"太绝对。低可及性是粗筛信号不是一票否决：正确做法是**降级分桶**——移出主推荐、标注低可及性留档（RNAplfold 只是体外近似，D20 结论 3）。另外注意一个反向可能：这个候选在 D21 的排序里本就该沉底，如果它排进了 top，先怀疑可及性计算有 bug |
| 8 链方向 | ❌ | 不会报错——分数错不改变程序合法性，**这是静默错误的教科书案例**。发现方法 = 断言：拿一条已知药物实测序列（Patisiran sense）跑打分，方向错则分数模式明显异常（15–19 与 1–5 的 A/U 分布互换）。这就是 D28 要放的第一条断言，也是 D21"验证管道必须断言中间量"的直接应用 |
