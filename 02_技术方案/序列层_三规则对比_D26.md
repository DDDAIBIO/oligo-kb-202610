## 1. Ui-Tei 2004（NAR 32:936–948）：四条件 AND 逻辑

以下四条**必须同时满足**（满足全部的 siRNA，报告实验中 98% 使荧光素酶表达降到 33% 以下——样本内验证）：

| # | 条件 | guide 坐标系表述* |
|---|---|---|
| i | 反义链（引导链）5′ 末端是 A/U | pos 1 ∈ {A,U} |
| ii | 正义链 5′ 末端是 G/C | pos 19 ∈ {G,C} |
| iii | 引导链 5′ 端三分之一（pos 1–7）富 A/U | 原文摘要 **≥5/7**；同组后续论文与 siDirect 实现用 **≥4/7** ⚠️ 版本漂移，见 §4 |
| iv | 全序列无 >9 nt 的连续 GC | 无 GC run ≥10 |

\* **guide 坐标系**：位置从引导链（反义链）5′ 端数起。原文用"antisense 5′ / sense 5′"表述，换算关系：sense pos k = guide pos (20−k)。**这套坐标系今天必须统一，否则三套规则没法对比。**

## 2. Amarzguioui & Prydz 2004：六条 ± 计分（cutoff ≥3）

| # | 条件 | 方向 |
|---|---|---|
| 1 | 双链两端末端 3 bp 的 A/U 差分（热力学不对称） | +1 |
| 2 | pos 19 是 G/C | +1 |
| 3 | pos 1 是 A/U | +1 |
| 4 | pos 14 是 A/U | +1 |
| 5 | pos 19 不是 U | −1 |
| 6 | pos 1 不是 G | −1 |

计分：正向特征 +1、反向 −1，**总分 ≥3 判有效**。注意它与 Reynolds 同为"计分制"，但**阈值口径完全不同**（3 vs 6，满分体系也不同：±体系 vs 0–10）。

## 3. 三套规则对比表（今天的核心产出）

| 维度 | Reynolds 2004 | Ui-Tei 2004 | Amarzguioui & Prydz 2004 |
|---|---|---|---|
| 形式 | 8 条累加，0–10 分，≥6 有效 | 4 条 AND，过/不过 | 6 条 ±，≥3 有效 |
| 共同核心 | 热力学不对称（15–19 富 A/U） | 条件 i+ii+iii 就是不对称 | 条件 1 就是显式不对称项 |
| pos 1 | +1（A19，guide 坐标即 pos1=A→不严格） | ∈{A,U} | ∈{A,U}，且非 G |
| **pos 19** | **G/C → −1**（偏好 A19） | **必须 G/C** | **G/C → +1**（且非 U） |
| GC 控制 | 30–52% 全窗 | 无 ≥10 连续 GC | 未直接约束 |
| 内部稳定性 | 内部重复 Tm*<20℃ +1 | 无此条 | 无此条 |
| 样本量 | 180 条 / 2 基因 | 62 条 / 6 基因、3 细胞系 🟡（回 PDF 核） | 🟡 未核（回 PDF 补） |
| 验证方式 | 29/30 rule-selected | 98% 降到 <33% | 🟡 |

### 3.1 真冲突：pos 19 一处三张脸

- Reynolds：G/C19 罚 1 分（A19 +1）——偏好**松的 3′ 端**；
- Ui-Tei：**必须** G/C19——要**紧的引导链 3′ 端**（这样 5′ 松 3′ 紧，不对称最大化）；
- Amarzguioui：G/C19 +1、U19 −1——同样偏好紧的 3′ 端。

三条规则**在同一位置给出相反排序**，而且**谁都说自己来自实验数据**。这正是"不合并权重"的第一条理由：合并 = 替读者仲裁实验证据。

### 3.2 机制一致性：为什么大体还是收敛的

用 D25 的因果链检查：**引导链 5′ 端松 → 5′ 磷酸先进 AGO2 MID 袋**。三套规则在"5′ 端要松"上完全一致（Reynolds 判据 2/4、Ui-Tei i+iii、Amarzguioui 1/3），分歧集中在**另一端（3′）要多紧**——这属于第二序问题，两派实验给出了相反的相关性。MID 结构域后来（Frank 2010）证明 A/U 单磷酸结合亲和力比 C/G 高约 30 倍 🟡（数字回原文核），给"5′ 端 A/U 偏好"补上了结构解释。

## 4. 二手漂移清单（今天最重要的方法论收获）

同一套规则在不同二手文献里会变形。已核到五处：

| # | 漂移 | 原文 | 二手 |
|---|---|---|---|
| 1 | Ui-Tei iii 阈值 | 摘要 **≥5/7** | 同组 2012 论文/siDirect 图 **≥4/7**——作者本人后续实现放宽，**版本漂移而非错误**，脚本需选定口径并注明 |
| 2 | GC stretch | 无 >9 nt 连续 GC | 某文献写成 ">4 bp"（抄错了） |
| 3 | Reynolds 内部稳定性符号 | Tm* < 20℃（低内稳） | 一篇写成 "Tm > 20℃"（**符号漂移**，语义反转） |
| 4 | Reynolds 条数 | 8 条 | "11 条"（C10 已收口） |
| 5 | **作者名** | Amarzguioui & **Prydz** 2004 | W4 细则写成 "Amarzguioui & Holen 2004" → **C11 更正**，细则已改 |

**教训（接 D23 编号）**：规则类知识必须**落到一手文献再进脚本**；二手综述的用途是找入口，不是抄参数。另外 **坐标系（sense vs guide numbering）本身就是最大的漂移源**——同一规则两套描述看起来像两条规则。

## 5. 脚本映射（D28 接口预览）

```python
def uitei_rule(guide: str) -> bool          # 四条件 AND, bool
def reynolds_score(sense: str) -> int       # 0-10
def amarzguioui_score(guide: str) -> int    # ±体系
# 输出表三列并存: uitei_ok / reynolds / amarzguioui
# 排序决策: reynolds 为主排序键(连续分可排序), uitei 作为硬过滤(AND 逻辑天然是过滤),
#          amarzguioui 分列展示。**不合成总分**。
```

为什么这样分工：AND 逻辑（Ui-Tei）天然是**过滤器**；连续计分（Reynolds）天然是**排序器**；± 计分（Amarzguioui）信息量介于两者之间，报告但不当主键。**混合三种量纲合成一个"总分"在数学上没有合法性**——这就是不合并权重的第二条理由。
