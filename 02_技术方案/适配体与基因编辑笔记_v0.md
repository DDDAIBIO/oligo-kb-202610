## 一句话结论

**适配体是五个模态里唯一"不靠碱基配对"的**——它靠折叠出的三维形状结合靶标，机理上更像抗体。
**基因编辑是唯一"不可逆"的**——前四个模态停药即衰减，Cas9 切错了永远留着。
这两条决定了它们各自的命运：一个被抗体的统治地位挤压，一个被"不可逆"带来的监管红线约束。

# 第一部分 · 适配体（Aptamer）

## 核心认知：它像抗体，不像核酸药

| 其它四个模态       | 适配体                |
| ------------ | ------------------ |
| 靠 Watson-Crick 碱基配对识别靶标 | **靠三维构象**识别靶标（形状匹配） |

> 类比：抗体靠 CDR 区构象识别抗原，适配体靠折叠出的口袋/发夹/四链体识别靶标。**两者的识别逻辑是同一类，与 ASO/siRNA 完全不同。**

## SELEX：怎么找到一条适配体

**Systematic Evolution of Ligands by EXponential enrichment** —— 体外指数富集的配体系统进化

1. 合成**随机文库**：10¹⁴–10¹⁵ 条随机序列（固定两端引物区 + 中间随机区）
2. **孵育**：文库与靶标蛋白混合
3. **分离**：洗掉不结合的 → 洗脱结合的
4. **扩增**：PCR（RNA 文库需先逆转录）
5. **重复 8–15 轮**，每一轮亲和力提升 → 最后高通量测序 + 生信分析挑候选

> **你的切入点**：第 5 步的 HTS-SELEX 数据分析正是生信活儿。已有工具：Aptamotif（序列-结构结合 motif 识别）、AptCompare（6 种 motif 发现程序的 meta-rank）、PATTERNITY、Galaxy 平台流程。

## 三个"补救"修饰（都是为了活下来）

适配体最大的短板是**体内半衰期只有分钟到小时级**（核酸酶降解 + 肾滤过快）。Pegaptanib 用了三层补救：

| 手段                        | 解决什么                             |
| ------------------------- | -------------------------------- |
| **2′-F 嘧啶 + 2′-OMe 嘌呤**    | 抗核酸酶降解                           |
| **3′ 端倒置 dT（3′-3′ dT）**    | 挡住 3′ 外切酶                        |
| **5′ 端 40 kDa 分支 PEG**     | 增大分子尺寸，减缓肾滤过                     |

> **代价**：原始 t44 克隆 KD = **10 pM**，全修饰后升到 **50 pM** —— **稳定���换来了 5 倍亲和力损失**。这是核酸药里反复出现的权衡，与 D2 的 gapmer 两翼修饰面临的是同一个问题。

## 案例拆解 4/5：Pegaptanib（Macugen）— ⚠️ 已撤市

| 维度   | 内容                                                                            |
| ---- | ----------------------------------------------------------------------------- |
| 靶点   | **VEGF165 亚型**（糖基化同源二聚体），2004-12 获批治疗湿性 AMD                                  |
| 长度   | **28 nt** RNA 适配体                                                             |
| 化学   | 2′-F 嘧啶 + 2′-OMe 嘌呤（仅剩 2 个未改）+ 3′-3′ dT + 40 kDa 分支 PEG                       |
| 亲和力  | KD ≈ 50 pM（原始克隆 10 pM）；**对 VEGF121 无可测亲和力**                                   |
| 半衰期  | 血清降解 18 h；猴玻璃体内 2 天；**人眼内约 10 天**                                              |
| 剂量   | **0.3 mg，每 6 周玻璃体内注射**                                                        |
| 疗效   | VISION III 期：1 年内视力丢失 <15 字母者 **70% vs 假注射组 55%**                             |
| 结局   | **已撤市**，FDA 批准于 **2025-05-09 正式撤回**                                            |

### 为什么输了（两个原因，第二个更重要）

1. **PK 劣势**：半衰期短，靠 PEG 才勉强撑住，给药频次与抗体相当但疗效弱
2. **选择性 ≠ 有效性**（⚠️ 核心教训）：Pegaptanib **只打 VEGF165 一个亚型**；而贝伐珠单抗/雷珠单抗/阿柏西普是 **pan-VEGF 阻断**，把所有 VEGFA 亚型都堵住 → 疗效更强

> **这句话记住**：在已有成熟疗法的适应症里，**"更特异"不是卖点，"更有效"才是**。适配体的优势（成本低、免疫原性低）不足以让医生换药。

## 现状：现在唯一在市的适配体

**Avacincaptad pegol（Izervay）** —— 抗 **C5** 的 PEG 化 RNA 适配体，**2023-08 获批**，用于干性 AMD 继发的**地理萎缩（GA）**。
（Pegaptanib 撤市后，它成为实际上的"唯一在市适配体"。）

> 其它在研：AS1411（26 nt 富 G DNA 适配体，形成 G-四链体，靶向核仁素，用于肾癌/胶质瘤/AML）。**适配体在诊断与递送上的应用远多于作为药物本身。**

# 第二部分 · 基因编辑药物

## CRISPR/Cas9 的两个组分

| 组分          | 干什么                    | 设计问题                    |
| ----------- | ---------------------- | ----------------------- |
| **Cas9 蛋白** | 核酸酶，在指定位置切双链           | 高保真变体选择；递送形式（蛋白 / mRNA） |
| **sgRNA**   | 20 nt 引导序列 + 支架，决定切哪里 | **on-target 效率 + 脱靶**   |

- 切割后主要由 **NHEJ**（非同源末端连接）修复 → 产生 indel → 移码或提前终止 → **永久敲除**
- 非分裂细胞（如肝细胞）中 NHEJ 占主导 → 当前体内策略**优先做"基因破坏"，不做"精确纠正"**

## 两条工程路线

|            | **ex vivo**（Casgevy）         | **in vivo**（NTLA-2001）            |
| ---------- | ---------------------------- | --------------------------------- |
| 编辑地点       | 体外，工厂里                       | 体内，患者体内                           |
| 递送         | **电转 Cas9 RNP**（无载体）         | **LNP 包 Cas9 mRNA + sgRNA**       |
| 质控         | **可先测序验证编辑效率再回输** ✅          | ❌ 打进去才知道，无法预检                     |
| 预处理        | ❌ **必须清髓化疗**（毒性大）            | ✅ 无需                              |
| 适用范围       | 血液系统（细胞可取、可植）                | 目前实质**只有肝**（LNP 天然富集）             |
| 代表药        | Casgevy（2023-12 获批）          | NTLA-2001（III 期）                  |
| 靶器官限制的根本原因 | 细胞能否离体操作并回输                  | **递送载体去哪**                        |

## 案例拆解 5/5·A：Casgevy（ex vivo）

| 维度      | 内容                                                                                                         |
| ------- | ---------------------------------------------------------------------------------------------------------- |
| 靶点      | **BCL11A 基因的红系特异性增强子区**（不是 BCL11A 基因本身！）                                                                    |
| 具体位点    | 增强子区的 **GATA1 转录因子结合位点**                                                                                   |
| 机制链     | 破坏 GATA1 位点 → 红系 BCL11A ↓ → γ-globin 去抑制 → **HbF（胎儿血红蛋白）↑**                                                 |
| 为什么这么设计 | **BCL11A 在 B 细胞、神经系统等其它谱系中必需，全身敲除不可接受** → 只破坏红系增强子 = **用一次编辑换来谱系选择性**                                      |
| 适应症     | ≥2 岁：镰状细胞病（伴复发性 VOC）、输血依赖型 β-地贫                                                                            |
| 剂量      | **≥3 × 10⁶ CD34+ cells/kg**，单次自体静脉输注                                                                       |
| 前置条件    | 给药前 48 h–7 天必须完成**清髓预处理**                                                                                  |
| 制剂      | 冻存悬液，5% DMSO + dextran 40                                                                                  |

> **这是全篇最优雅的一步。** 它提示了一个巨大的计算机会：**如何找到"谱系特异性"的调控元件？** 这正是 ATAC-seq / ChIP-seq / 单细胞多组学的活儿。

## 案例拆解 5/5·B：NTLA-2001 / nex-z（in vivo）

| 维度   | 内容                                                                                      |
| ---- | --------------------------------------------------------------------------------------- |
| 靶点   | **TTR 基因 exon 2**（野生型与变异型共有的保守区）→ 一次敲除覆盖所有转录本                                           |
| 制剂   | **LNP 包裹 SpCas9 mRNA + sgRNA**，单次静脉输注                                                    |
| 机制   | 进入肝细胞 → 胞质翻译出 Cas9 → 入核与 sgRNA 结合 → 切 TTR → NHEJ 产生 indel → **永久敲除**                     |
| 疗效   | ATTRv-PN 一期：28 天内血清 TTR 降低 **>90%**ATTR-CM（NEJM 2024，n=36）：28 天 **−89%**，12 个月 **−90%**，维持至 24 个月 |
| ⚠️ 安全 | **2025-10-27** 一例 4 级肝转氨酶 + 总胆红素升高 → **2025-10-29 FDA 正式临床搁置**（MAGNITUDE + MAGNITUDE-2） |
| 后续   | 2026-01-27 MAGNITUDE-2 先解禁；**2026-03-02** MAGNITUDE 修订安全监测方案后重启入组                         |

### 这件事的三个教训

1. **LNP 本身是肝毒性来源** —— 对已有器官受累的高危人群，大剂量 LNP 的局部炎症/补体激活是致命风险
2. **不可逆性放大了风险厌恶** —— siRNA 出问题可以停药；**Cas9 切错了永远留着**。所以监管红线远高于可逆转的模态
3. **一例就能叫停 450+ 例的试验** —— 慢性非致死适应症里，风险容忍度极低

> 对比：同为降 TTR，siRNA（vutrisiran/patisiran）需反复给药但**可逆**；基因编辑一次给药但**不可逆**。这两种风险画像对应完全不同的监管态度。

## 计算切入点（阶段二/三要动手的）

1. **sgRNA on-target 效率预测** —— 序列特征 + 染色质状态 → 编辑效率。工具方向：DeepCas9 / CRISPick 类打分模型
2. **sgRNA 脱靶预测** —— 序列比对 + 错配容忍建模；高保真 Cas9 变体选择
3. **脱靶检测实验的数据分析** ⭐ —— **GUIDE-seq / CHANGE-seq / DISCOVER-seq 全部产出 NGS 数据**，从 raw reads 到全基因组脱靶位点鉴定是完整的一条生信管线。**这是你十年测序功底最直接能变现的地方。**
4. **编辑效率定量** —— amplicon-seq 的 indel 谱分析（CRISPResso2）
5. **谱系特异性调控元件识别** ⭐ —— Casgevy 那个思路的通用化：用 ATAC-seq + ChIP-seq + 单细胞多组学找"只在目标细胞类型活跃"的增强子，作为编辑靶点。**别人做不了，你能做。**
6. **HTS-SELEX 数据分析**（适配体方向）→ Aptamotif / AptCompare

## 自检（先自己答，再点开）

<details>

<summary>1. 适配体和 ASO/siRNA 最根本的区别是什么？</summary>

其它模态靠**碱基配对**（序列决定打谁），适配体靠**三维构象**（折叠形状决定结合谁）。所以适配体的靶标不一定是核酸，可以是蛋白质、细胞、甚至小分子——机理上更像抗体。

</details>

<details>

<summary>2. 适配体在亲和力、成本、免疫原性上都不输抗体，为什么上市的这么少？</summary>

两个原因：① **体内半衰期只有分钟到小时级**（核酸酶降解 + 肾滤过），必须靠 2′ 修饰与 PEG 化补救，且补救会带来亲和力损失；② 已有成熟抗体疗法的适应症里，**"更特异"不构成换药理由**——必须"更有效"才行。Pegaptanib 输给 Lucentis 就是因为只打 VEGF165 一个亚型，而抗体是 pan-VEGF 阻断。

</details>

<details>

<summary>3. Casgevy 为什么不直接敲除 BCL11A 基因？</summary>

因为 BCL11A 在 B 细胞、神经系统等其它谱系中是必需基因，全身敲除不可接受。解法是只破坏它的**红系特异性增强子**（具体是增强子区的 GATA1 结合位点）——这样 BCL11A 只在红细胞系里降低，其它谱系不受影响。**用一次编辑换来谱系选择性。**

</details>

<details>

<summary>4. ex vivo 和 in vivo 基因编辑，各自最大的优势和最大的代价是什么？</summary>

- **ex vivo**：最大优势是**可质控**（回输前能测序验证编辑效率），最大代价是**需要清髓化疗**且只适用于血液系统
- **in vivo**：最大优势是**无需预处理、可及性好**，最大代价是**无法预检**且递送目前实质只有肝（LNP 天然富集）这一条路

</details>

<details>

<summary>5. 2025 年 10 月 NTLA-2001 的临床搁置事件，说明了什么？</summary>

三点：① **LNP 本身是肝毒性来源**，对已有器官受累的高危人群风险放大；② **基因��辑不可逆**，监管风险容忍度远低于可停药的 siRNA（同为降 TTR，siRNA 可逆）；③ 在慢性非致死适应症中，**单例严重不良事件就足以叫停 450+ 例的 III 期试验**。所以"一次给药终身治愈"的叙事，其代价是极高的安全性门槛。

</details>
