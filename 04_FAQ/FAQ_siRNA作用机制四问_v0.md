> 来源：D25 学习当天（2026-11-16）的四次追问，答案已按机理串成一条线。
> 关联文档：`02_技术方案/序列层_siRNA设计规则Reynolds_D25.md`、D20 位点层、D22 验证层 SOP。

## Q1：热力学不对称里说"5′ 端配对松"——是和谁配对松？

**答：和同一条双链里的另一条链配对松，不是和靶 mRNA。** siRNA 是自配对的双链体，"松/紧"描述的全是**链内两条链之间**的碱基配对强度。

因果链（背这一条就够）：

> sense 15–19 富 A/U → 反义链 5′ 端配对松 → 松端先解链 → 反义链 5′ 磷酸被 AGO2 的 MID 结构域扣住 → 反义链成为引导链 → seed 打向目标 mRNA

四个要点：

1. **几何关系**：两链反向平行，反义链 5′ 端正好对着 **sense 第 15–19 位**——这就是 Reynolds 判据 2 的几何来源（sense 15–19 = antisense 1–5）。
2. **松端决定方向**：双链两端稳定性不同，装载时**松端先解开**，装载复合体靠这个不对称定向——哪条链的 5′ 端落在松端，哪条链被选为引导链。
3. **为什么 5′ 端关键**：AGO2 的 **MID 结构域**只认引导链的 5′ 磷酸并物理锚定，引导链以 5′ 端为起点伸出 seed（2–8）扫靶。选错引导链 = seed 朝错误方向开路 = 去沉默互补于正义链的转录本。
4. **类比**：双链像拉链，只能从比较松的那头拉开；拉开哪头，决定露出来的是哪条链的 5′ 端。

## Q2：AGO2 蛋白是什么、怎么工作？

**答：AGO2（Argonaute 2）是 RISC 的切割引擎**，约 859 aa，四个结构域各管一件事：

| 结构域 | 抓什么 | 对应的设计规则 |
| --- | --- | --- |
| **MID** | 引导链 **5′ 磷酸**（物理扣住） | 热力学不对称 → 5′ 端落在松端的链被它抓住 = 引导链 |
| **PAZ** | 引导链 **3′ 端** | 3′ 突出端（dTdT / UU）可被容纳 |
| **PIWI** | **RNase H 样催化中心**（下刀处） | U10 规则——切割发生在靶链 **10/11 位之间** |
| **N** | 辅助装载、passenger 链切除 | — |

三个关键点：

1. **引导链躺着工作**：5′ 端进 MID、3′ 端进 PAZ，全链固定在 AGO2 沟里，只有**第 2–8 位裸露成 seed 区**。D22"seed 介导脱靶"的物理根源就是这 7 个碱基：不参与切割、只做初始扫描。
2. **切割是"验证后处决"**：seed 扫到互补 → 配对向 3′ 延伸 → 全程互补则 PIWI 在靶链 10/11 之间一刀切断。siRNA 引导链全配对 → 切割（**催化级联，一个 AGO2 切多条 mRNA**）；miRNA 中心区常错配 → 不切，只抑制翻译。
3. **为什么"松端"能定向**：装载时先松开的那端把对应的 5′ 磷酸送进 MID 口袋——MID 只认 5′ 磷酸，**谁先到谁被锁**。

**口诀：MID 抓头（5′），PAZ 抓尾（3′），PIWI 下刀（10/11），seed 认路（2–8）。**
这一句能把 D22 的 seed 脱靶、D25 的八条判据、热力学不对称全部串在同一个蛋白上。

## Q3：seed（2–8 位）没有完全配对，会产生什么结果？

**答：取决于错配发生在哪一段。** 三种情形结局完全不同：

| 情形 | 结局 | 对应知识库条目 |
| --- | --- | --- |
| **全程配对** | seed 成核 → 配对延伸 → PIWI 在 10/11 切割 → mRNA 被处决 ✅ | siRNA 正常工作路径 |
| **seed 配上，但中心区（10–11）错配** | **不切割**，但 seed 扣住靶 → miRNA 路线：抑制翻译 / 促脱腺苷酸化（弱、面广）⚠️ | **D22 的 B 类 seed 介导脱靶**——引导链把 3′UTR 带同源 seed 的基因全按 miRNA 方式压一遍 |
| **seed 区本身错配**（含靶 mRNA 上落 SNP） | **成核失败** → AGO2 抓不稳 → 结合解离 → **无切割也无抑制，什么效应都没有** ❌ | **D20 的 SNP 规则**（seed 区 MAF≥5% → 0 分）罚的就是这种：药效在该等位基因上失效 |

**关键不对称：seed 配对是"入场券"（没有它什么都不发生），中心配对决定"处决还是镇压"。**

两条设计推论：

1. seed 区 SNP = 药效命门 → `scan_sites` 里 seed 区常见 SNP 直接 0 分。
2. B 类脱靶只需要 6–7 nt seed 同源（1 kb 3′UTR 随机命中约 6%）——**完全匹配搜索永远看不见它**，只能靠 RNA-seq seed 富集分析（D22 §4）。`offtarget_scan` 查"≥15-mer 完全匹配"抓的是 A 类，两类必须分开报。

---

## 一句话总结

> seed 配对是入场券，中心配对决定处决还是镇压；热力学不对称决定谁拿到入场券（谁当引导链），而执行处决的刀就是 AGO2 的 PIWI。

## Q4：Inclisiran（Leqvio）为什么是皮下注射？

**答：因为它是 GalNAc 偶联 + ESC+ 化学——自带的"导航"和"护甲"替代了 LNP 载体，而没有 LNP，就没有输液反应和慢速输注的限制，皮下推注就够。**

用核心方程（核酸药 = 药效团 + 分布团 + 作用机制）拆开：

### 4.1 GalNAc = 分布团（去哪）

三价 GalNAc 高亲和力结合**只在肝细胞表面表达的 ASGPR**（去唾液酸糖蛋白受体），受体介导内吞把药带进肝细胞，受体随后循环回表面继续干活。皮下注射后药物入血，靠这条受体通路精确送达肝脏——**导航由配体完成，不依赖载体颗粒**。对比 Patisiran 的 LNP 走 ApoE/LDLR 通路，靠的是"颗粒大小恰好被肝脏捡走"，精度低一档。

### 4.2 ESC+ 修饰 = 药效团活着到达（护甲）

裸 siRNA 在血浆里几分钟就被核酸酶降解——这是早期 siRNA 必须"裹起来"的原因。Inclisiran 的骨架是 2′-F / 2′-OMe 高密度修饰 + 偶联连接链上的 PS：**修饰本身在血浆和组织里护住 RNA，递送载体这个"大件"整个省掉**。对应速查表 §2.4"修饰的代价表"里 2′-F / 2′-OMe 买到的东西。

### 4.3 没有 LNP，注射方式就轻了

| | Patisiran（LNP 路线） | Inclisiran（GalNAc 路线） |
| --- | --- | --- |
| 载体 | LNP 颗粒 60–100 nm，可触发输液反应 | 约 20 kDa 级偶联物 🟡（具体分子量待核） |
| 给药 | 慢速 IV 输注 + 输注前预处理用药 | 皮下推注，无需预处理 |
| 场所 | 输液诊所 | 门诊/社区即可 |
| 肝靶向机制 | ApoE/LDLR 通路（被动） | ASGPR 受体介导（主动） |
| 给药频次 | 每 3 周（初始） | 0/3 月各一针，之后**每半年一针**（叠加修饰带来的长组织滞留） |

### 4.4 不要忽略的细节：内吞体逃逸是最低效的一步

GalNAc 通路里，内吞后逃逸到细胞质的比例很低 🟡（文献常引个位数百分比量级，具体数字待核）。GalNAc 平台的逻辑是**用受体专一性换数量**：药量大、逃逸比例虽低但绝对数够用。这与 LNP 靠膜融合高效逃逸是两条不同的工程哲学。

### 4.5 对应知识库

- D18 核心方程的活案例：**分布团（GalNAc）解决去哪，药效团（修饰 siRNA）保证到了能干活**，缺一个都不成立。
