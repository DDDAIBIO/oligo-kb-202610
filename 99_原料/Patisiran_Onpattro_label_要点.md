# Patisiran / ONPATTRO —— label 要点摘抄

> 来源：openFDA `drug/label`，version 11，effective_time **2025-09-08**
> 原文 json：`99_原料/patisiran_label.json`
> 拆解日期：2026-11-02（W2 · 第 3 周 递送主题）
> 摘抄原则：只抄 label 原文写明的，label 没写的一律标「⚠️ 待核」不补

---

## 1. 一句话定位

**首个获批的 LNP 递送 siRNA**（2018-08，Alnylam），靶 TTR mRNA，适应症 hATTR 淀粉样变多发性神经病。
它是「递送方式如何决定整个用药方案」的最佳教材——见 §6 与 Vutrisiran 的天然对照。

---

## 2. 靶点与机制（label §12.1 原文）

> "Patisiran is a double-stranded siRNA that causes degradation of **mutant and wild-type TTR mRNA** through RNA interference..."

- 靶序列位于 TTR mRNA 的 **3′UTR 保守区**，且**突变型与野生型通吃**。
- ⭐ 对比记忆：NTLA-2001（基因编辑）打的是 **TTR exon 2**；siRNA 打 **3′UTR**。
  同一基因、同一疾病，可成药位点不止一个——**"选哪个区域"本身就是一个设计决策**。

---

## 3. 序列与化学修饰（label §11 DESCRIPTION 原文）

label 给出的字母表：`A, C, G, U, Cm (2′-O-methylcytidine), Um (2′-O-methyluridine), dT (thymidine)`

- 修饰策略：**所有嘧啶 (C/U) 为 2′-OMe，嘌呤保持 2′-OH**；末端含 dT。
- 分子式（钠盐）：`C412 H480 N148 Na40 O290 P40`，MW **14,304 Da**

### 分子式反推练习（用已建立的套路）

| 元素 | 数字 | 推断 | 交叉验证 |
|---|---|---|---|
| **P = 40** | 磷酸连接数 | 公式 `P = 核苷酸总数 − 链数` → 40 + 2 = **42 nt（21+21 双链）** | ✅ 与文献「21/21 双链」吻合 |
| **S = 0** | PS（硫代磷酸）数 | **完全不含 PS** | ⭐ 见下方说明 |
| **Na = 40** | 钠离子数 | = P 数，电荷中性 | ✅ 40 个磷酸负电荷 ↔ 40 个 Na⁺ |

> ⚠️ **Na 是钠离子，不是核苷酸**（这是最容易数错的一处）。

### ⭐ 为什么 patisiran 可以 0 个 PS？

| | ASO（如 Nusinersen） | Patisiran（LNP-siRNA） |
|---|---|---|
| 核酸酶保护 | 靠 **PS 骨架**（17/17 全长） | 靠 **LNP 包封 + 2′-OMe**（label §12.3：>95% 与脂质复合物结合） |
| 进入细胞方式 | 裸分子被细胞摄取 | LNP 内吞 |

**"保护"这件事可以用骨架做，也可以用递送系统做。** 这是「化学修饰层 ↔ 递送层可互相替代」的第一个实例，也是本周的核心命题。

## 4. LNP 配方（label §11 原文，每 1 mL）

| 组分 | 类别 | 量 (mg/mL) |
|---|---|---|
| patisiran | 载荷 | **2** |
| **DLin-MC3-DMA**（MC3） | 可电离脂质 | **13.0** |
| Cholesterol | 胆固醇 | **6.2** |
| DSPC | 辅助磷脂 | **3.3** |
| PEG2000-C-DMG | PEG-脂质 | **1.6** |
| 磷酸盐 / NaCl | 缓冲与等渗 | 0.2 / 8.8 |

**计算：总脂质 = 13.0 + 6.2 + 3.3 + 1.6 = 24.1 mg → 脂质/RNA 质量比 ≈ 12 : 1**

> 对照 Spikevax（SM-102 体系）脂质/RNA ≈ **20 : 1**（见 `Spikevax_mRNA-1273_label_要点.md`）。
> 同样的 LNP 平台，mRNA 比 siRNA 需要更多脂质——因为 **mRNA 长约 4 kb，是 siRNA 的近 200 倍**，包装负担不是一个量级。

- pH ≈ 7.0；2–8 °C 保存，**不可冻**（冻了颗粒就散了）。

### 顺手的练习（可选）

已知 MC3 MW 642.1、DSPC 790.2、cholesterol 386.7，文献经典 MC3-LNP 摩尔比为 **50 : 10 : 38.5 : 1.5**。
用上面的质量数反推摩尔比，看能对上多少（PEG2000-C-DMG 的 MW 需自查，这是唯一不确定的一项）。

## 5. 给药方案与预处理（label §2）

- **0.3 mg/kg IV 输注，每 3 周一次**；体重 ≥100 kg 者给 30 mg。
- 输注时长 **约 80 分钟**；需过滤并稀释后给药。

### ⭐ §2.2 必需预处理（Required Premedication）—— 本周最重要的证据

所有患者输注前必须给药，**且至少提前 60 分钟**：

| 预处理 | 举例 |
|---|---|
| IV 糖皮质激素 | 地塞米松 10 mg 或等效 |
| 口服对乙酰氨基酚 | 500 mg |
| IV H1 阻断剂 | 苯海拉明 50 mg 或等效 |
| IV H2 阻断剂 | （label 列有） |

**为什么？** label 写明是为降低 **输注相关反应（IRR）** 风险。

> 这就是 LNP 免疫原性不是理论问题的**直接监管证据**：
> 一个药如果本身足够"干净"，是不需要在每次给药前给患者打激素 + 抗组胺的。
> 而 GalNAc-siRNA（Vutrisiran / Inclisiran）的 label 里**没有这一节**。

## 6. PK（label §12.3）

| 参数 | 数值 |
|---|---|
| 剂量线性 | 0.01–0.5 mg/kg 范围内线性 |
| 循环中与脂质结合比例 | **> 95%** |
| 稳态达峰 | 治疗 **24 周**后 |
| Cmax（稳态） | 7.15 ± 2.14 µg/mL |
| Ctrough（稳态） | 0.021 ± 0.044 µg/mL |
| AUCτ（稳态） | 184 ± 159 µg·h/mL |
| AUC 蓄积 | 首剂的 **3.2 倍** |
| 分布容积 Vss | 0.26 ± 0.20 L/kg（**主要分布肝**） |
| 血浆蛋白结合 | **≤ 2.1%**（极低） |
| 终末半衰期 | **3.2 ± 1.8 天** |
| 清除 | 主要经核酸酶代谢为不同长度核苷酸；尿排 < 1% |

> 注意血浆蛋白结合仅 ≤2.1%——因为它 >95% 都"躲在"脂质复合物里，没机会碰白蛋白。
> 对照 Vutrisiran（裸偶联物）血浆蛋白结合 **80%**，差异巨大。

## 7. 年治疗负担的算账（自己算一遍，建立直觉）

按 70 kg 患者：

| 项 | 计算 | 结果 |
|---|---|---|
| 单次剂量 | 0.3 × 70 | 21 mg |
| 年给药次数 | 365 / 21 | **17.3 次** |
| **年剂量** | 21 × 17.3 | **≈ 364 mg** |
| 年输注时长 | 80 min × 17.3 | **≈ 1384 min ≈ 23 小时** |

> 记住 364 mg 这个数字，然后去看 Vutrisiran 的 100 mg。
