## 一、Fitusiran（Qfitlia，Genzyme / Sanofi，2025-03 获批）

### 基本信息

| 项 | 内容 |
|---|---|
| 模态 | GalNAc 偶联 **双链 siRNA** |
| 靶点 | **抗凝血酶 AT**（antithrombin，基因 `SERPINC1`）mRNA |
| 适应症 | 血友病 A/B（**伴或不伴抑制物**）常规预防，≥12 岁，降低出血频次 |
| 分子式 | `C520 H636 F21 N175 Na43 O309 P43 S6` |
| 分子量 | **17,193 Da** |
| 给药 | **皮下**，起始 50 mg **每 2 个月**；另有 20 mg / 50 mg 规格 |
| label 版本 | 2025-09-16 v6 |

### ⚠️ 黑框警告（这是三款里唯一有黑框的）

> **WARNING: THROMBOTIC EVENTS AND ACUTE AND RECURRENT GALLBLADDER DISEASE**

- **血栓事件**：危险因素包括 AT 活性持续 <15%、**80 mg 每月**给药、留置静脉导管、围手术期未遵循出血管理指引
- **急性/复发性胆囊疾病**：部分患者需胆囊切除，或并发胰腺炎
- 另有常规警告：**肝毒性**（基线查肝功，起始及加量后至少 6 个月内每月查）

### PD/PK：一个"必须按生物标志物滴定"的药物

- PD 指标 = **血浆 AT 活性**，目标窗 **15–35%**
- label 原句：*`"QFITLIA PD is driven by liver PK rather than plasma PK."`*
- 模拟：无论何种给药方案，>99% 受试者 AT 达稳态需约 **23 周**

> **这一款的教学价值**：它不是"固定剂量"，而是**把 AT 活性当成一个治疗窗来滴定**。
> 降太多 → 血栓；降不够 → 还是会出血。血友病本来是"凝血不足"，结果靠**降低抗凝因子**来重平衡止血——
> 这个"以毒攻毒"的逻辑值得单独想一遍。

## 二、Donidalorsen（Dawnzera，Ionis，2025-08-21 获批）

### 基本信息

| 项 | 内容 |
|---|---|
| 模态 | GalNAc 偶联 **ASO gapmer** |
| 靶点 | **前激肽释放酶 PKK**（prekallikrein，基因 `KLKB1`）mRNA → 降缓激肽 |
| 适应症 | 遗传性血管性水肿（HAE）预防，成人及 ≥12 岁青少年 |
| 分子式 | `C296 H415 N83 O151 P20 S15 Na20` |
| 分子量 | **9,112.27 Da** |
| 给药 | **皮下 80 mg 每 4 周**（也可考虑 80 mg 每 8 周），预充式自动注射器 |
| 首个人体 | OASIS-HAE（NCT05139810，24 周，双盲安慰剂对照，n=90） |

### ⭐ 结构：label 里给了**完整化学名**，可以直接数出来（这是本原料最值钱的部分）

化学名（label 原文节选，已简化符号）：

```
d([2′-MOE]m5rU-sp-[2′-MOE]rG-sp-[2′-MOE]m5rC-[2′-MOE]rA-[2′-MOE]rA-
  sp-G-sp-T-sp-m5C-sp-T-sp-m5C-sp-T-sp-T-sp-G-sp-G-sp-m5C-sp-
  [2′-MOE]rA-[2′-MOE]rA-[2′-MOE]rA-sp-[2′-MOE]m5rC-sp-[2′-MOE]rA)
  5′-[...GalNAc3 配体...]
```

**自己数一遍（对照分子式交叉验证）**：

| 数什么 | 结果 | 交叉验证 |
|---|---|---|
| 核苷酸总数 | **20 个** | 分子式 **P20** ✓ |
| 2′-MOE 翼部 | 5′ 端 **5 个** + 3′ 端 **5 个** | — |
| DNA gap（裸 Bu，无 MOE） | **10 个**（`G-T-T-m5C-T-m5C-T-T-G-G`） | — |
| ⇒ 构型 | **标准的 5-10-5 gapmer** | 完美复现 D2 学的架构 |
| 硫代磷酸 `-sp-` | **15 个**（19 个连接里有 15 个 PS，4 个保留天然磷酸二酯） | 分子式 **S15** ✓ |
| gap 内含 m5C | 有（5-甲基胞嘧啶） | 提高 Tm 的常见做法 |

> **这是 D2 的现场验证**：课本上的"5-10-5 gapmer"不是示意图，2025 年获批的真药就是这么写的。
> 另外注意 **PS 只有 15/19**——不是全长 PS（对比 Nusinersen 全长 17 个 PS）。
> 减少 PS 是当前趋势：PS 带来血浆蛋白结合（延长循环）但也带来补体激活/肝摄取的代价，能省则省。

### PD 数据（labels 12.2）

- Week 4 血浆 PKK 平均下降 **48%**
- Week 24 谷浓度：Q4W 组降 **73%**、Q8W 组降 **47%**，安慰剂组反而升 2%

### 安全性

- 最常见 ADR：注射部位反应、上呼吸道感染、尿路感染、腹部不适
- **中重度肝损伤不推荐使用**；PMR 要求评估 DILI 风险（4 年 OLE）

## 三、Plozasiran（Redemplo，Arrowhead，2025-11 获批）

### 基本信息

| 项 | 内容 |
|---|---|
| 模态 | GalNAc 偶联 **双链 siRNA** |
| 靶点 | **apoC-III**（载脂蛋白 C-III）mRNA → 促进甘油三酯清除 |
| 适应症 | 家族性乳糜微粒血症综合征（**FCS**），辅助饮食控制降 TG |
| 分子式 | `C493 H611 F11 N164 Na43 O311 P43 S7` |
| 分子量 | **16,563.98 Da** |
| 给药 | **皮下 25 mg 每 3 个月** |
| label 版本 | 2026-08-25 v4 |

### 化学修饰（label 明写了）

- 核糖 2′ 位全部为 **2′-F** 或 **2′-OMe**
- 每条链含若干 PS（分子式 **S7**）
- label 图例中列了所有缩写：**A/A、C/C、G/G、U/U（分别对应 2′-OMe 与 2′-F）**，另外有 **`I = 2′-O-甲基肌苷`**

> ⚠️ **注意 `I` 出现在 plozasiran 里**：肌苷（inosine，源自 A→I 脱氨）作为修饰核苷出现在已上市 siRNA 中了。
> 这一点大多数中文资料不会提，写 siRNA 序列工具时**记得在字母表 I 上别报错**。

### PK（label 12.3，健康成人 25 mg）

| 参数 | 值 |
|---|---|
| Cmax | 68.5 ng/mL |
| Tmax（中位） | 6 小时 |
| 血浆蛋白结合率 | 78% |
| 表观分布容积 | ≈ 146 L（分布到血浆 + 细胞外液，再被肝细胞摄取） |
| **血浆终末半衰期** | **3–4 小时** |
| 系统清除率 | 33.8 L/h |

> **又见 PK/PD 脱耦**：血浆半衰期只有 3–4 小时，却能**每 3 个月一针**。和 Inclisiran（9 h / 半年一针）是同一个逻辑——
> 药效来自肝细胞内的 RISC 库，不是血浆浓度。

## 四、横向对照：三款药放在一起看

| | Fitusiran | Donidalorsen | Plozasiran |
|---|---|---|---|
| 商品名 | Qfitlia | Dawnzera | Redemplo |
| 企业 | Genzyme (Sanofi) | Ionis | Arrowhead |
| 获批 | 2025-03 | 2025-08-21 | 2025-11 |
| 模态 | siRNA | **ASO gapmer 5-10-5** | siRNA |
| 靶基因 | SERPINC1 (AT) | KLKB1 (PKK) | APOC3 |
| 适应症 | 血友病 A/B | HAE | FCS |
| 分子量 | 17,193 Da | 9,112 Da | 16,564 Da |
| 递送 | GalNAc（肝） | GalNAc（肝） | GalNAc（肝） |
| **剂量/间隔** | 50 mg Q2M | 80 mg Q4W（或 Q8W） | 25 mg Q3M |
| **分子数/剂** | 1.75×10¹⁸ | 5.29×10¹⁸ | 9.09×10¹⁷ |
| 安全性亮点 | **黑框：血栓 + 胆囊病** | 肝损伤慎用 | — |

### 唯一结论：三款都是 GalNAc + 肝

**三个完全不同的疾病、两套模态（siRNA / ASO）、三个靶点——递送平台是同一个。**

这正是 D1 那张"解耦图"的产业兑现：分布团（GalNAc）一旦跑通，后续药物的**变量就只剩序列**。
这也是为什么 2025 年能一年批三款——不是三次创新，是**一次底盘 + 三次 repurpose**。
