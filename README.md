## 规范

- **命名**：`[类别]_[主题]_[版本]_[日期].md`，如 `SOP_siRNA设计管线_v1.1_20270315.md`
- **结构**：一律套用各目录下的 `_模板.md`
- **标签**：`#siRNA #ASO #mRNA #结构预测 #ML #脱靶 #专利 #速查表`
- **纪律**：每天至少一次 commit；`NOW.md` 记录断点
- **状态标注**：有效 / 待更新 / 已废弃 / 仅供参考
