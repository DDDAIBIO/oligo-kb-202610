## 4. 本周的结构性发现（候选 5 条，本人删改保留 3 条）

1. **"跑出结果"≠"交付完成"**：D28/D29/D30 连续三次「服务器有数据、知识库零记录」——`TTR_siRNA_candidates.tsv`、`TTR_offtarget_summary.tsv`、top10 整合表都不在仓库。**任务卡的验收标准必须写"入库路径"**。
2. **预核验是本周最高杠杆的动作**：D28 抓 3 个手算坑（判据 7/8 纯罚分、amarz ⑤⑥、串长 18→19）、D29 抓 3 个（G_RC 反向互补、filler 撞碱基、contig 边界）——**你端零 debug**。规则化：凡含我手算/参考实现的断言，必须先本机全绿再交付。
3. **凡"双链"契约，验证脚本也必须双链**：D29 的 drill 脚本只扫 guide 链，12-mer 悬案实际在 passenger 链上——"口径不对称"第 N 次变体（前有 guide=target 混填、链方向反、19 vs 21 坐标）。
4. **join 的映射不是 1:1**：D21 21-mer 窗口与 D28 19-mer 候选是「一个 19-mer 内含于最多 3 个 21-mer」（窗口起点 t ∈ [s−2, s]）；"差 1"只在**中心对齐**口径下成立。可及性取"内含窗口 max mean_access"还是"中心对齐 t=s−1"，必须写进整合表的口径说明。
5. **事实纪律的成本在复核，不在查找**：C10–C12 + 手算 revcomp + filler 撞碱基，两周 5 次判断被推翻。结论：**"我记得/通常是"开头的数字一律现查**；文件实际行数优先于心算累加。
